    Painel

    O Painel é a primeira tela que você vê após fazer login no Dino. Ele serve como seu hub central para navegar pelo aplicativo. Dependendo da configuração do seu sistema, seu Painel aparecerá em um dos dois layouts: um Painel de Menu ou um Painel de Relatórios.

    Painel de Menu

    Neste layout, o Painel apresenta uma grade de cartões de navegação. Cada cartão fornece acesso rápido a uma área principal do aplicativo que você tem permissão para usar.

    Você normalmente verá os seguintes cartões:

    • Formulários: Navegue até a área de Formulários para criar esquemas de formulários, coletar dados e revisar submissões.
    • Relatórios: Navegue até a área de Relatórios para criar, visualizar e gerenciar relatórios baseados nos dados coletados.
    • Métricas: Navegue até a área de Métricas para gerenciar dados de referência como projetos, locais e organizações. !!! warning "Visibilidade" O cartão de Métricas fica oculto se sua conta de usuário tiver permissões apenas de convidado.
    • Usuários: Navegue até a área de Gerenciar Usuários para gerenciar contas de usuário e grupos. !!! tip "Acesso de Administrador" O cartão de Usuários só é visível para usuários com privilégios de administrador.

    Para navegar, basta clicar no cartão da área que deseja acessar.

    Painel de Relatórios

    Neste layout, seu Painel é personalizado para exibir um único relatório que você marcou como favorito. Isso permite visualizar visualizações de dados importantes imediatamente após o login.

    Se você ainda não selecionou um relatório favorito, verá uma mensagem de boas-vindas solicitando que adicione um.

    Definindo um Relatório Favorito

    1. Vá para a área de Relatórios.
    2. Abra o relatório que deseja ver em seu Painel.
    3. Na lista de relatórios ou na visualização do relatório, encontre e clique na ação Adicionar aos favoritos (geralmente representada por um ícone de estrela).
    4. Atualize ou retorne ao seu Painel. O relatório selecionado será exibido agora.

    Alterando ou Removendo um Favorito

    Para alterar seu relatório favorito, basta adicionar outro relatório aos seus favoritos. O novo relatório substituirá o antigo em seu Painel. Para limpar o Painel, você pode remover a configuração de relatório favorito do armazenamento local do seu navegador ou entrar em contato com o administrador do sistema.

    Tour Guiado

    Na primeira vez que você acessar o Dino, um tour guiado pode iniciar automaticamente a partir do Painel para apresentar as principais funcionalidades do aplicativo.

    • Você pode seguir as instruções na tela para aprender sobre navegação e ações principais.
    • Se você pular ou terminar o tour, pode reiniciá-lo a qualquer momento a partir do menu de ajuda na Área do Usuário.
