    Dashboard

    La Dashboard è la prima schermata che vedi dopo aver effettuato l'accesso a Dino. Funge da hub centrale per la navigazione nell'applicazione. A seconda della configurazione del sistema, la tua Dashboard apparirà in uno dei due layout: una Dashboard a Menu o una Dashboard a Report.

    Dashboard a Menu

    In questo layout, la Dashboard presenta una griglia di schede di navigazione. Ogni scheda fornisce accesso rapido a un'area principale dell'applicazione che hai il permesso di utilizzare.

    Di solito vedrai le seguenti schede:

    • Forms: Vai all'area Moduli per creare schemi di moduli, raccogliere dati e rivedere le risposte.
    • Reports: Vai all'area Report per creare, visualizzare e gestire report basati sui dati raccolti.
    • Metrics: Vai all'area Metriche per gestire dati di riferimento come progetti, luoghi e organizzazioni. !!! warning "Visibilità" La scheda Metriche è nascosta se il tuo account utente ha solo permessi da ospite.
    • Utenti: Vai all'area Gestione Utenti per gestire account e gruppi di utenti. !!! tip "Accesso Amministratore" La scheda Utenti è visibile solo agli utenti con privilegi di amministratore.

    Per navigare, basta cliccare sulla scheda dell'area che si desidera visitare.

    Dashboard a Report

    In questo layout, la tua Dashboard è personalizzata per mostrare un singolo report che hai contrassegnato come preferito. Questo ti consente di visualizzare immediatamente le visualizzazioni dei dati chiave dopo l'accesso.

    Se non hai ancora selezionato un report preferito, vedrai un messaggio di benvenuto che ti invita ad aggiungerne uno.

    Impostare un Report Preferito

    1. Vai all'area Report.
    2. Apri il report che desideri vedere sulla tua Dashboard.
    3. Nell'elenco dei report o nella vista del report, trova e clicca l'azione Aggiungi ai preferiti (solitamente rappresentata da un'icona a stella).
    4. Aggiorna o torna alla tua Dashboard. Il report selezionato verrà ora visualizzato.

    Modificare o Rimuovere un Preferito

    Per cambiare il tuo report preferito, aggiungi semplicemente un report diverso ai preferiti. Il nuovo report sostituirà il precedente sulla tua Dashboard. Per cancellare la Dashboard, puoi rimuovere l'impostazione del report preferito dalla memoria locale del browser o contattare il tuo amministratore di sistema.

    Tour Guidato

    La prima volta che accedi a Dino, un tour guidato potrebbe avviarsi automaticamente dalla Dashboard per presentarti le funzionalità principali dell'applicazione.

    • Puoi seguire le istruzioni sullo schermo per conoscere la navigazione e le azioni principali.
    • Se salti o finisci il tour, puoi riavviarlo in qualsiasi momento dal menu di aiuto nell'Area Utente.
