# Métricas

As métricas são as categorias de dados de referência usadas em todo o Dino para classificar, organizar e filtrar os dados coletados. Ao preencher um formulário ou gerar um relatório, você seleciona valores dessas categorias — por exemplo, escolhendo um projeto, uma localização ou uma organização.

A área de Métricas é onde você gerencia as listas de valores disponíveis para cada categoria. Ela serve como o ponto central para todos os seus dados de referência.

---

## Tipos de Métricas

A página principal exibe os tipos de métricas ativos na sua instalação do Dino. Cada tipo é mostrado como um cartão com um ícone e um rótulo. Clique em qualquer cartão para abrir sua página de gerenciamento.

Dependendo da configuração do seu sistema, alguns ou todos os seguintes tipos de métricas podem estar disponíveis:

| Tipo de Métrica | Descrição |
|---|---|
| **Áreas Temáticas** | Áreas de trabalho ou agrupamentos temáticos para suas atividades. |
| **Casos** | Casos individuais, pessoas ou beneficiários acompanhados em envios de formulários. |
| **Localizações** | Localizações geográficas onde os dados são coletados ou onde as atividades ocorrem. |
| **Projetos** | Projetos aos quais os envios de formulários e relatórios estão vinculados. |
| **Organizações** | Organizações envolvidas ou responsáveis pelas atividades. |

!!! tip "Acessando as Métricas"
    Você pode navegar até a área de Métricas clicando em **Métricas** no menu principal do aplicativo.

---

## O Que Você Pode Fazer

Na página principal de Métricas, você pode:

1.  **Visualizar todos os tipos de métricas ativos** disponíveis para seus dados.
2.  **Navegar para um tipo de métrica específico** clicando no cartão dele. Isso leva você a uma página dedicada onde você pode gerenciar a lista de valores desse tipo (por exemplo, adicionar uma nova localização ou editar o nome de um projeto).
3.  **Usar trilhas de navegação** no topo da página para acompanhar seu caminho de navegação na seção de Métricas.

Para instruções detalhadas sobre como adicionar, editar ou excluir valores em um tipo de métrica específico, consulte a documentação de cada tipo de métrica: [Áreas](areas.md).

---

## Navegando pela Área de Métricas

1.  Na página principal de Métricas, analise os cartões de cada tipo de métrica disponível.
2.  Clique no cartão do tipo de métrica que você deseja gerenciar (por exemplo, **Localizações**).
3.  Você será direcionado para uma página dedicada a esse tipo de métrica, onde poderá visualizar, adicionar, editar ou excluir valores específicos.
4.  Use a trilha de navegação no topo da página para voltar facilmente à página principal de Métricas ou a outras seções.

!!! warning "Configuração do Sistema"
    Os tipos de métricas disponíveis são configurados pelo administrador do seu sistema. Se você não encontrar um tipo de métrica específico de que precise, entre em contato com o administrador.
