# Relatórios

A área de Relatórios é o seu ponto central para acessar todos os esquemas de relatório disponíveis. Um esquema de relatório define a estrutura e o conteúdo de um relatório que pode ser gerado a partir dos seus dados coletados. A partir daqui, você pode navegar pelos esquemas e acessar os relatórios que já foram criados.

![Visão principal da página de Relatórios](../imgs/reports/index.png)

Os relatórios só podem ser criados usando um formulário baseado em Excel chamado [XLSReport](xlsreport.md). Para criar um novo relatório, você precisa primeiro criar um arquivo XLSReport e depois importá-lo para o Dino seguindo o procedimento descrito abaixo.

---

## Navegando pelos Esquemas de Relatório

Ao abrir a página de Relatórios, você vê uma lista de todos os esquemas de relatório que tem permissão para acessar. A lista é ordenada alfabeticamente pelo rótulo do esquema.

Para encontrar um esquema específico:

1. Use a barra de pesquisa no topo da página.
2. Digite qualquer parte do nome ou rótulo do esquema.
3. A lista será filtrada em tempo real para mostrar apenas os esquemas correspondentes.

Para visualizar os relatórios de um esquema específico, clique no cartão correspondente na lista.

!!! tip "Primeiros Passos"
    Se você vir a mensagem "There are no reports", significa que nenhum esquema de relatório foi criado ainda ou compartilhado com você. Entre em contato com o administrador do Dino para começar.

---

## Criando um Novo Esquema de Relatório

Você pode iniciar o processo de geração de um novo esquema de relatório diretamente na página principal de Relatórios. Clique no botão **+** (mais) localizado no canto inferior direito da tela.

Para etapas detalhadas, consulte o guia sobre [Editar Relatório](edit-report.md).

---

## O Que Você Pode Fazer

Na página principal de Relatórios, você pode navegar para realizar estas ações principais:

* **[Editar Relatório](edit-report.md)** — Gere um novo documento de relatório selecionando um esquema, escolhendo suas métricas e definindo um intervalo de datas.
* **[Editar Esquema de Relatório](edit-report-schema.md)** — Crie novos esquemas de relatório ou edite os existentes para definir quais dados aparecem nos relatórios. Isso geralmente requer permissões de administrador.
