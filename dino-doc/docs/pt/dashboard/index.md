# Painel

O Painel é a primeira tela que você vê após fazer login no Dino. Ele serve como ponto central de navegação no aplicativo. Dependendo da configuração do seu sistema, o seu Painel será exibido em um dos dois layouts: um **Painel de Menu** ou um **Painel de Relatório**.

![Vista principal da página do Painel](../imgs/dashboard/index.png)

---

## Painel de Menu

Neste layout, o Painel apresenta uma grade de cartões de navegação. Cada cartão fornece acesso rápido a uma área principal do aplicativo que você tem permissão para usar.

Normalmente, você verá os seguintes cartões:

*   **Formulários**: Navegue até a área de [Formulários](../forms/index.md) para criar esquemas de formulário, coletar dados e revisar as submissões.
*   **Relatórios**: Navegue até a área de [Relatórios](../reports/index.md) para criar, visualizar e gerenciar relatórios com base nos dados coletados.
*   **Métricas**: Navegue até a área de [Métricas](../metrics/index.md) para gerenciar dados de referência, como projetos, localizações e organizações.
    !!! warning "Visibilidade"
        O cartão Métricas fica oculto se a sua conta de usuário tiver apenas permissões de convidado.
*   **Usuários**: Navegue até a área de [Gerenciar Usuários](../administration/users-list.md) para gerenciar contas e grupos de usuários.
    !!! tip "Acesso de Administrador"
        O cartão Usuários só é visível para usuários com privilégios de administrador.

Para navegar, basta clicar no cartão da área que você deseja acessar.

## Painel de Relatório

Neste layout, o seu Painel é personalizado para exibir um único relatório que você marcou como favorito. Isso permite que você veja as principais visualizações de dados imediatamente após o login.

Se você ainda não selecionou um relatório favorito, verá uma mensagem de boas-vindas pedindo que você adicione um.

### Como Definir um Relatório Favorito

1.  Vá para a área de [Relatórios](../reports/index.md).
2.  Abra o relatório que deseja ver no seu Painel.
3.  Na lista de relatórios ou na visualização do relatório, localize e clique na ação **Adicionar aos favoritos** (geralmente representada por um ícone de coração).
4.  Atualize ou volte ao seu Painel. O relatório selecionado agora será exibido.

### Como Alterar ou Remover um Favorito

Para alterar o seu relatório favorito, basta adicionar um relatório diferente aos seus favoritos. O novo relatório substituirá o antigo no seu Painel. Para limpar o Painel, você pode remover a configuração do relatório favorito do armazenamento local do seu navegador ou entrar em contato com o administrador do sistema.
