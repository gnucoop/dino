# Bem-vindo ao Dino

Dino é uma plataforma web para a coleta, o monitoramento e a análise de dados estruturados. Ela oferece às equipes um único lugar para criar formulários de coleta de dados, reunir informações do campo, acompanhar o progresso e explorar resultados — seja online ou em ambientes com pouca conectividade.

---

## O Que Você Pode Fazer com o Dino

### Coletar e Gerenciar Dados
Crie a estrutura dos formulários, chamada de form schema, e use-os para coletar informações. Visualize e gerencie todos os seus dados no [Painel](dashboard/index.md) principal. Você pode criar, editar e organizar suas ferramentas de coleta de dados.

*   [Visualizar e Gerenciar Formulários](forms/index.md)
*   [Criar um Form Schema](forms/edit-form-schema.md)
*   [Preencher um Formulário](forms/edit-form.md)
*   [Importar Dados de Fontes Externas](forms/import.md)
*   [Explorar Dados em um Mapa](forms/forms-map.md)

### Analisar e Gerar Relatórios
Transforme os dados coletados em insights. Crie relatórios personalizados e use a IA para fazer perguntas sobre seus dados em linguagem natural.

*   [Visualizar e Gerenciar Relatórios](reports/index.md)
*   [Criar um Report Schema](reports/edit-report-schema.md)
*   [Preencher um Relatório](reports/edit-report.md)
*   [Converse com Seus Dados](forms/datachat.md)
*   [Agregar Dados](aggregation/index.md)

### Marcar seus dados com tags
Atribua tags de tipos predefinidos — chamados de métricas — aos seus dados, a fim de permitir a segregação de dados (por meio de permissões de acesso), a agregação de dados e a criação de relacionamentos entre formulários.
Os tipos de métricas predefinidos são: áreas, casos, locais, organizações e projetos.

*   [Visão Geral das Métricas](metrics/index.md)
*   [Gerenciar Áreas Temáticas](metrics/areas.md)
*   [Gerenciar Casos](metrics/cases.md)
*   [Gerenciar Locais](metrics/locations.md)
*   [Gerenciar Organizações](metrics/organizations.md)
*   [Gerenciar Projetos](metrics/projects.md)

## Acesso e Permissões

O que você pode ver e fazer no Dino depende dos grupos de permissão atribuídos à sua conta. Algumas áreas — como a administração e o gerenciamento de form schema — só são visíveis para usuários com o papel apropriado. Se você não encontrar um recurso descrito nesta documentação, entre em contato com o administrador do sistema.
