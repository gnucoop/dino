# Usuarios

El área de **Usuarios** es el centro principal para gestionar quién puede acceder a Dino y qué puede hacer. Desde aquí, puede navegar a dos secciones clave de administración: **Usuarios** (para cuentas individuales) y **Grupos** (para conjuntos de permisos).

![Main view of the Users page](../imgs/administration/users.png)

Al abrir la página de Usuarios, verá un menú con las siguientes opciones:

*   **Usuarios**: Abre la página [Gestionar Usuarios](users-list.md) para crear, editar y gestionar cuentas de usuario individuales.

    Al hacer clic en esta opción, accederá a la lista de usuarios, donde podrá ver todas las cuentas, agregar nuevos usuarios, editar detalles y desactivar cuentas.

    ![Main view of the Users List page](../imgs/administration/users-list.png)

*   **Grupos**: Abre la página [Grupos](groups-list.md) para crear y gestionar grupos de permisos que controlan el acceso a formularios, informes y datos.

Simplemente haga clic en cualquiera de los elementos del menú para ir a la sección correspondiente.

!!! warning "Se requiere acceso de Administrador"
    El área de Usuarios solo es visible para los usuarios con el rol de Administrador. Si no puede ver esta página, contacte a su administrador del sistema.
