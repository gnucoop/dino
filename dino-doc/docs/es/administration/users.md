# Usuarios

El área de **Usuarios** es el centro principal para gestionar quién puede acceder a Dino y qué puede hacer. Desde aquí, puedes navegar a dos secciones de administración clave: **Usuarios** (para cuentas individuales) y **Grupos** (para conjuntos de permisos).

![Main view of the Users page](../imgs/administration/users.png)

Cuando abras la página de Usuarios, verás un menú con las siguientes opciones:

*   **Usuarios**: Abre la página [Administrar usuarios](users-list.md) para crear, editar y gestionar cuentas de usuario individuales.

    Al hacer clic en esta opción, accederás a la lista de usuarios, donde podrás ver todas las cuentas, añadir nuevos usuarios, editar detalles y desactivar cuentas.

    ![Main view of the Users List page](../imgs/administration/users-list.png)

*   **Grupos**: Abre la página [Grupos](groups-list.md) para crear y gestionar grupos de permisos que controlan el acceso a formularios, informes y datos.

Simplemente haz clic en cualquiera de los elementos del menú para navegar a la sección correspondiente.

!!! warning "Se requiere acceso de administrador"
    El área de Usuarios solo es visible para los usuarios con el rol de Administrador. Si no puedes ver esta página, contacta con el administrador del sistema.
