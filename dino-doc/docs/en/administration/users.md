# Users

The **Users** area is the central hub for managing who can access Dino and what they can do. It gives you access to two administration sections: **Users** for individual accounts and **Groups** for permission sets that control access to forms, reports, and data.

![Main view of the Users page](../imgs/administration/users.png)

The page displays a menu with one tile for each section. Click a tile to open that section.

## Available Sections

### Users

The **Users** tile opens the [Manage Users](users-list.md) page. Use it to create new accounts, review existing ones, update user details, and deactivate accounts that are no longer needed.

![Main view of the Users List page](../imgs/administration/users-list.png)

### Groups

The **Groups** tile opens the [Groups](groups-list.md) page. Groups bundle permissions together so you can assign the same access rights to several users at once. Use this section to create groups and adjust their permissions. Users are assigned to groups from each user's editor, in the **User Permission Groups** field.

## Opening a Section

1. Open the **Users** page from the main navigation.
2. Click the tile for the section you want to work in — **Users** or **Groups**.
3. Dino takes you to the list for that section, where you can work with individual accounts or group definitions.

!!! tip "Start with groups"
    If several people need the same level of access, set up a group first and then assign it to each of them in the **User Permission Groups** field of the user editor. This keeps permissions consistent and saves you from editing each account separately.

!!! warning "Administrator Access Required"
    The Users area is only visible to users with the Administrator role. If you cannot see this page, contact your system administrator.
