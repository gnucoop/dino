# Метрики

Метрики — це довідкові категорії даних, які використовуються в Dino для класифікації, впорядкування та фільтрування зібраних даних. Метрики можна пов’язувати зі зібраними формами, а потім використовувати для визначення visualizzazioni даних вашого встановлення. Наприклад, метрики можна застосовувати для визначення дозволів користувачів: конкретному користувачеві можна надати доступ лише до деяких значень метрик. Це може бути корисно, наприклад, у міжнародній організації, якщо ви хочете обмежити доступ певних користувачів лише даними країни, у якій вони працюють. Так само ви можете обмежувати доступ користувачів Dino за іншими критеріями, використовуючи інші метрики, як-от метрику «Проєкт», щоб обмежити доступ лише до деяких проєктів, або метрику «Організація», щоб обмежити доступ лише до даних деяких партнерів.

Окрім обмеження доступу до даних, метрики також можна використовувати для полегшення фільтрів й агрегацій. Наприклад, мені може знадобитися порахувати, скільки форм було зібрано для певної країни. У цьому випадку я можу відфільтрувати дані форм за значенням метрики «Locations». Фільтри також можуть скористатися перевагами ієрархічної структури метрик. Наприклад, якщо в мене є структура «Locations», скажімо, з трьома рівнями, тому що я зіставляю провінції (тобто значення метрики для кожної провінції), згруповані в регіони (тобто значення метрики для кожного регіону, яке також використовується як батьківське для провінцій), згруповані в країни (тобто значення метрики для кожної країни, яке використовується як батьківське для регіонів). Отже, у цьому випадку я міг би відфільтрувати всі форми певного регіону, просто відфільтрувавши регіон, чим самим вибравши всі провінції, які належать до того самого регіону.

Цей механізм також можна використовувати під час генерації report. Дані report певного report schema можна згенерувати за допомогою конкретного значення метрики. Це означатиме, що report schema застосовується до всіх форм, які мають те саме значення метрики, відповідно до ієрархії значень метрики.

Нарешті, метрики можна використовувати для зв’язування даних різних форм. Наприклад, у мене може бути form для персональних даних підопічних — один на особу — а потім інший form для їхніх медичних візитів — більше ніж один на особу. Метрику «Cases» можна використовувати, щоб зв’язати form персональних даних із формами візитів, а також щоб скопіювати частину даних із form персональних даних, як-от дату народження, у форми медичних візитів.

Різні способи використання метрик роблять цю сутність потужним інструментом для керування даними.

Розділ «Метрики» — це місце, де ви керуєте списками доступних значень для кожної категорії. Він слугує центральним вузлом для всіх ваших довідкових даних.

## Типи метрик

Головна сторінка відображає типи метрик, які активні у вашому встановленні Dino. Кожен тип показано як картку з іконкою та підписом. Натисніть на будь-яку картку, щоб відкрити її сторінку керування.

Залежно від конфігурації вашої системи можуть бути доступні деякі або всі з наведених нижче типів метрик:

| Тип метрики | Опис |
|---|---|
| **Тематичні напрями** | Напрями роботи або тематичні групування для вашої діяльності. |
| **Справи** | Окремі справи, особи або підопічні, яких відстежують у даних форм. |
| **Locations** | Географічні місця, де збирають дані або відбувається діяльність. |
| **Проєкти** | Проєкти, з якими пов’язані дані форм і report. |
| **Організації** | Організації, залучені до діяльності або відповідальні за неї. |

!!! tip "Доступ до метрик"
    Ви можете перейти до розділу «Метрики», натиснувши **Метрики** в головному меню застосунку.

## Що ви можете робити

На головній сторінці «Метрики» ви можете:

1.  **Переглянути всі активні типи метрик**, доступні для ваших даних.
2.  **Перейти до певного типу метрики**, натиснувши його картку. Це приведе вас на окрему сторінку, де ви можете керувати списком значень для цього типу (наприклад, додати новий location або змінити назву проєкту).
3.  **Скористатися навігаційним ланцюжком** угорі сторінки, щоб відстежувати свій шлях навігації в межах розділу «Метрики».

Докладні інструкції щодо додавання, редагування або видалення значень у межах певного типу метрики дивіться в документації для кожного типу метрики:

- [Areas](areas.md)
- [Cases](cases.md)
- [Locations](locations.md)
- [Organizations](organizations.md)
- [Projects](projects.md).

## Навігація розділом «Метрики»

1.  На головній сторінці «Метрики» перегляньте картки для кожного доступного типу метрики.
2.  Натисніть картку типу метрики, яким хочете керувати (наприклад, **Locations**).
3.  Ви перейдете на окрему сторінку для цього типу метрики, де можете переглядати, додавати, редагувати або видаляти конкретні значення.
4.  Скористайтеся навігаційним ланцюжком угорі сторінки, щоб легко повернутися на головну сторінку «Метрики» або до інших розділів.

!!! warning "Конфігурація системи"
    Доступні типи метрик налаштовує ваш системний адміністратор. Якщо ви не бачите потрібний тип метрики, зверніться до адміністратора.

!!! warning "Видалення значення метрики"
    Це стосується всіх метрик. Видалення значення метрики, наприклад певного location або справи, може вплинути на форми, які на нього посилаються. Саме тому перед видаленням значення метрики система перевіряє, чи є в Dino будь-який елемент, пов’язаний із цим значенням. Якщо є дані форми, дані report або будь-яке посилання в дозволах, видалення цього значення буде заборонено. Перш ніж видаляти значення метрики, переконайтеся, що жодні активні записи на нього не покладаються.
