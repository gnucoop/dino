# Метрики

Метрики — це категорії довідкових даних, які використовуються в Dino для класифікації, впорядкування та фільтрування зібраних даних. Метрики можна пов'язувати зі зібраними form, а потім використовувати для визначення visualizzazione даних вашої інсталяції. Наприклад, метрики можна використовувати для визначення дозволів користувачів: конкретному користувачеві можна надати доступ лише до деяких значень метрик. Це може бути корисно, наприклад, у багатокраїнній організації, якщо ви хочете обмежити доступ певних користувачів лише даними тієї країни, де вони працюють. Так само можна обмежити доступ користувачів Dino за іншими критеріями, використовуючи інші метрики, як-от метрику проекту, щоб обмежити доступ лише до деяких проектів, або метрику організації, щоб обмежити доступ лише до даних деяких партнерів.

Окрім обмеження доступу до даних, метрики також можна використовувати для полегшення фільтрів та агрегацій. Наприклад, я можу порахувати, скільки form було зібрано для певної країни. У цьому разі я можу відфільтрувати дані своїх form за значенням метрики місцезнаходження. Фільтри також можуть скористатися ієрархічною структурою метрик. Наприклад, якщо я маю структуру місцезнаходжень, скажімо, з трьома рівнями, бо я відображаю провінції (тобто значення метрики для кожної провінції), згруповані в регіони (тобто значення метрики для кожного регіону, яке також використовується як батьківське для провінцій), згруповані в країни (тобто значення метрики для кожної країни, яке використовується як батьківське для регіонів). Отже, у цьому разі я міг би відфільтрувати всі form певного регіону, просто відфільтрувавши регіон, тим самим вибравши всі провінції, що належать до того самого регіону.

Цей механізм також можна використовувати під час створення report. Дані report певного report schema можна згенерувати, використовуючи конкретне значення метрики. Це означатиме, що report schema застосовується до всіх form, які мають те саме значення метрики, відповідно до ієрархії значень метрики.

Нарешті, метрики можна використовувати для пов'язування даних різних form. Наприклад, я можу мати form для персональних даних бенефіціарів — одну на особу — а потім іншу form для їхніх медичних візитів — більше ніж одну на особу. Метрику справа можна використовувати, щоб пов'язати form персональних даних з form візитів, а також щоб скопіювати деякі дані з form персональних даних, як-от дату народження, до form медичних візитів.

Різні способи використання метрик роблять цю сутність потужним інструментом для керування даними.

Розділ Метрики — це місце, де ви керуєте списками доступних значень для кожної категорії. Він слугує центральним вузлом для всіх ваших довідкових даних.

## Типи метрик

Головна сторінка відображає типи метрик, активні у вашій інсталяції Dino. Кожен тип показано як картку з піктограмою та назвою. Натисніть на будь-яку картку, щоб відкрити її сторінку керування.

Залежно від конфігурації вашої системи можуть бути доступні деякі або всі з наведених нижче типів метрик:

| Тип метрики | Опис |
|---|---|
| **Тематичні області** | Напрями роботи або тематичні групування вашої діяльності. |
| **Справи** | Окремі справи, особи або бенефіціари, яких відстежують у даних form. |
| **Місцезнаходження** | Географічні місцезнаходження, де збирають дані або відбувається діяльність. |
| **Проекти** | Проекти, з якими пов'язані дані form та report. |
| **Організації** | Організації, залучені до діяльності або відповідальні за неї. |

!!! tip "Доступ до Метрик"
    Ви можете перейти до розділу Метрики, натиснувши **Метрики** в головному меню застосунку.

## Що ви можете робити

На головній сторінці Метрик ви можете:

1.  **Переглянути всі активні типи метрик**, доступні для ваших даних.
2.  **Перейти до конкретного типу метрик**, натиснувши його картку. Це приведе вас на окрему сторінку, де ви можете керувати списком значень для цього типу (наприклад, додати нове місцезнаходження або змінити назву проекту).
3.  **Використовувати percorso di navigazione** вгорі сторінки, щоб відстежувати шлях навігації в межах розділу Метрики.

Докладні інструкції щодо додавання, редагування або видалення значень у межах конкретного типу метрик дивіться в документації для кожного типу метрик:

- [Тематичні області](areas.md)
- [Справи](cases.md)
- [Місцезнаходження](locations.md)
- [Організації](organizations.md)
- [Проекти](projects.md).

## Навігація розділом Метрики

1.  На головній сторінці Метрик перегляньте картки для кожного доступного типу метрик.
2.  Натисніть картку типу метрик, яким хочете керувати (наприклад, **Місцезнаходження**).
3.  Ви перейдете на окрему сторінку для цього типу метрик, де можете переглядати, додавати, редагувати або видаляти конкретні значення.
4.  Використовуйте ланцюжок percorso di navigazione вгорі сторінки, щоб легко повернутися на головну сторінку Метрик або до інших розділів.

!!! warning "Конфігурація системи"
    Доступні типи метрик налаштовує ваш системний адміністратор. Якщо ви не бачите потрібного типу метрик, зверніться до адміністратора.

!!! warning "Видалення значення метрики"
    Це стосується всіх метрик. Перш ніж видалити значення метрики, наприклад певне місцезнаходження або справу, Dino перевіряє, чи воно ще використовується. Якщо його використовує якась form або воно має дочірні значення, видалення відхиляється (*Some forms use these metrics. You cannot delete them.* / *Some metrics have children. You cannot delete them.*). Якщо його використовують лише report, ви отримуєте попередження і все одно можете підтвердити. Дозволи груп, які посилаються на це значення, **не** перевіряються: видаліть його з будь-якої групи перед видаленням.
