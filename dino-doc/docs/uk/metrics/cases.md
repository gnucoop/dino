# Справи

Сторінка «Справи» — це централізований робочий простір для відстеження та керування окремими справами. Кожна справа — це структурований запис, який може містити назву, код, зображення, зв’язок із батьківською справою, примітки та додаткові атрибути. Ви можете створювати нові справи, редагувати наявні, переглядати деталі, видаляти записи та експортувати список справ — усе це з однієї інтерактивної таблиці.

![Головний вигляд сторінки «Справи»](../imgs/metrics/cases.png)

## Огляд таблиці

Головна таблиця за замовчуванням показує такі стовпці:

- **Назва справи** — назва, яку ви присвоюєте справі (можна сортувати).
- **Код** — код, згенерований системою або призначений вручну (лише для читання після створення).
- **Зображення справи** — завантажений файл зображення, що представляє справу.
- **Батьківська справа** — назва батьківської справи, до якої належить ця справа.

Додаткові стовпці (як-от **ID**, **Примітки**, **Дата створення** та **Додаткові атрибути**) приховані за замовчуванням. Ви можете налаштувати, які стовпці відображаються, натиснувши кнопку **Налаштувати стовпці** у заголовку таблиці.

## Дії з однією справою

Праворуч у кожному рядку ви знайдете значки для таких дій:

- **Редагувати** — відкриває діалогове вікно для зміни деталей справи.
- **Друк** — створює картку справи у форматі PDF для друку.
- **Переглянути** — відкриває діалогове вікно лише для читання, щоб оглянути інформацію про справу.
- **Видалити** — відкриває діалогове вікно підтвердження для остаточного видалення справи.

Натисніть значок **Більше** (три вертикальні крапки), щоб побачити всі доступні дії, якщо частина з них прихована.

## Масові дії

Виберіть кілька справ за допомогою прапорців у першому стовпці. Коли вибрано принаймні одну справу, угорі таблиці з’являється кнопка **Видалити**. Ви можете видалити всі вибрані справи одразу.

!!! warning "Масове видалення є остаточним"
    Видалені справи неможливо відновити. Використовуйте масове видалення обережно.

## Створення нової справи

1. Натисніть плаваючу кнопку дії **Додати нову** (значок плюса) в нижньому правому куті сторінки.
2. Відкриється діалогове вікно. Заповніть обов’язкові поля:
   - **Назва справи** — введіть описову назву.
   - **Код** — (Необов’язково) Вкажіть унікальний код. Це поле доступне лише для читання після створення.
   - **Зображення справи** — завантажте файл зображення.
   - **Батьківська справа** — за бажанням пов’яжіть цю справу з наявною батьківською справою.
   - **Примітки** — додайте будь-які доречні примітки.
3. Натисніть **Зберегти**, щоб створити справу.

## Імпорт справ

Скористайтеся плаваючою кнопкою дії **Імпорт** (значок завантаження в хмару), щоб масово завантажити справи з файлу. Підтримувані формати визначає ваш системний адміністратор.

## Фільтрування та пошук

Рядок пошуку вгорі дає змогу фільтрувати справи за:

- **Ключовим словом** — пошук у всіх відображуваних полях.
- **Діапазоном дат** — фільтр за датою створення (Від / До).
- **Додатковими фільтрами** — вибір із наперед визначених фільтрів, як-от метрика, статус, користувач або група користувачів.

Після застосування фільтрів ви можете зберегти комбінацію як **пресет** для швидкого повторного використання. Щоб зберегти пресет:

1. Відкрийте панель фільтрів.
2. Введіть назву в полі пресета.
3. Натисніть **Зберегти**.  
Щоб застосувати збережений пресет, виберіть його зі списку та натисніть **Застосувати**.

## Експорт справ

Натисніть кнопку **Експорт** (значок завантаження з хмари) на панелі фільтрів. Виберіть формат експорту (наприклад, CSV або Excel) і позначте, які стовпці включити. Експортований файл міститиме всі поточні видимі справи з урахуванням активних фільтрів.

## Налаштування таблиці

- **Сортування** — натисніть заголовок будь-якого стовпця, який можна сортувати (наприклад, **Назва справи**, **Дата створення**), щоб упорядкувати таблицю.
- **Вибір стовпців** — відкрийте діалогове вікно вибору стовпців, щоб показати або приховати стовпці.
- **Розгортання рядків** — деякі справи можуть мати підпорядковані елементи (інші справи, пов’язані як деталі). Натисніть рядок, щоб розгорнути його та побачити пов’язані записи.

Сторінка також показує **навігаційний ланцюжок** угорі, щоб ви могли повернутися до головного розділу «Метрики».
