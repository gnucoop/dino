# Навігація та інтерфейс

Інтерфейс Dino складається з верхньої панелі інструментів і бічного меню навігації, які присутні на кожній сторінці після входу в систему.

![Main view of the Main Nav page](../imgs/interface/index.png)

---

## Бічна навігація

Бічне меню дозволяє переходити між основними розділами застосунку.

**Стандартні розділи** (видимі для всіх автентифікованих користувачів):

| Розділ | Опис |
|---|---|
| Панель керування | Головний екран. |
| Форми | Форми збору даних і подання. |
| Звіти | Згенеровані звіти. |
| Агрегація | Об'єднаний перегляд подань із кількох форм. |
| Метрики | Довідкові дані (проєкти, локації, організації тощо). *(Приховано для користувачів лише з гостьовим доступом.)* |
| ШІ | ШІ-асистент (DinoGPT). |

**Адміністративні розділи** (видимі лише адміністраторам, показані нижче розділювача):

| Розділ | Опис |
|---|---|
| Користувачі | Облікові записи користувачів і групи дозволів. |
| Мови | Керування перекладами інтерфейсу. |

На великих екранах меню завжди видиме ліворуч. На менших екранах воно згортається, і його можна відкрити за допомогою **кнопки меню** (іконки-гамбургера) у верхній панелі інструментів. На будь-якому розмірі екрана натисніть кнопку меню, щоб розгорнути підписи меню або згорнути їх до іконок.

## Верхня панель інструментів

Панель інструментів у верхній частині екрана містить такі елементи керування зліва направо:

- **Перемикач меню** — відкрити або згорнути бічне меню.
- **Логотип** — відображає логотип вашої організації.
- **Індикатор нової версії** — з’являється іконка завантаження, коли доступна нова версія Dino. Натисніть її, щоб перезавантажити застосунок і застосувати оновлення.
- **Кредити DINO-AI** — показує ваш залишок кредитів ШІ у вигляді значка. Натисніть, щоб відкрити [Область користувача](#user-area) на панелі «Кредити». *(Видимо лише якщо налаштовано ключ API DINO-AI.)*
- **Перемикач темного / світлого режиму** — іконка сонця, повзунок та іконка місяця. Використовуйте повзунок, щоб перемикатися між світлою та темною темами. *(Приховано на мобільних пристроях — скористайтеся Областю користувача.)*
- **Іконка інформації** — наведіть курсор, щоб побачити інформацію про версію цієї інсталяції.
- **Іконка довідки** — відкриває плейлист навчальних посібників Dino у новій вкладці.
- **Іконка налаштувань** — відкриває [Область користувача](#user-area).
- **Іконка синхронізації** — показує поточний стан синхронізації даних. Натисніть, щоб запустити ручну синхронізацію.
- **Дзвінок сповіщень** — показує кількість непрочитаних сповіщень у вигляді значка. Дзвінок дзвенить, коли надходять нові сповіщення. Див. [Сповіщення](#notifications) нижче.
- **Вибір мови** — перемикає мову інтерфейсу.
- **Ім’я користувача** — натисніть, щоб відкрити [Область користувача](#user-area).
- **Іконка виходу** — натисніть, щоб вийти. Іконка затемнена, коли триває синхронізація або пристрій перебуває в автономному режимі; вихід недоступний у цих станах.

## Синхронізація даних

Dino синхронізує ваші дані з сервером у фоновому режимі. **Іконка синхронізації** на панелі інструментів показує поточний стан:

| Іконка | Значення |
|---|---|
| `sync` (статична) | Усі дані актуальні. |
| `sync_problem` (пульсує) | У вас є локальні зміни, які ще не синхронізовано. Натисніть, щоб запустити синхронізацію. |
| `sync` (обертається) | Зараз триває синхронізація. |
| `sync_disabled` | Пристрій перебуває в автономному режимі; синхронізація недоступна. |
| `sync` зі значком `!` | Виникла проблема синхронізації. Перевірте свої сповіщення для деталей. |

Коли синхронізація завершується, унизу екрана короткочасно з’являється сповіщення:

- *«Синхронізацію завершено»* — усі дані успішно синхронізовано.
- *«Синхронізацію завершено з помилками. Не вдалося синхронізувати: [елементи]. Перевірте сповіщення.»* — один або кілька наборів даних не вдалося синхронізувати. Також створюється сповіщення у вашому списку сповіщень.

## Сповіщення

Натисніть **іконку дзвінка** на панелі інструментів, щоб відкрити спадний список сповіщень. Значок на дзвінку показує кількість непрочитаних повідомлень.

![Notifications dropdown open](../imgs/interface/index-notifications.png)

У цьому спадному списку ви можете:

1.  **Клацнути сповіщення**, щоб позначити його як прочитане.
2.  **Клацнути кнопку зі стрілкою** на сповіщенні (якщо вона є), щоб перейти безпосередньо до відповідного розділу застосунку.
3.  **Позначити всі як прочитані** — позначає всі поточні сповіщення як прочитані.
4.  **Переглянути всі сповіщення** — веде до повної сторінки [Сповіщення](../notifications/index.md).

## Область користувача

Натисніть **іконку налаштувань**, своє **ім’я користувача** або **лічильник кредитів DINO-AI**, щоб відкрити діалог області користувача. Угорі відображаються ваше повне ім’я та адреса електронної пошти.

![User area dialog open](../imgs/interface/index-user-area.png)

### Зміна пароля

1.  Введіть **поточний пароль**.
2.  Введіть **новий пароль**.
3.  **Підтвердьте новий пароль**.
4.  Натисніть кнопку зі стрілкою, щоб зберегти.

Повідомлення про помилку з’явиться, якщо поточний пароль неправильний або нові паролі не збігаються.

### Ключі API

Перегляньте або встановіть **ключ API DINO-AI**. Після збереження дійсного ключа його показано в режимі лише для читання. Використовуйте іконку ока, щоб показати або приховати ключ, та іконку копіювання, щоб скопіювати його в буфер обміну.

### Кредити

Показує ваш поточний **баланс кредитів DINO-AI**. Якщо налаштовано платіжну інтеграцію, доступна кнопка **Додати ще** для придбання додаткових кредитів.

!!! tip "Видимість"
    Цей розділ видимий лише тоді, коли налаштовано ключ API DINO-AI.

### Тема DINO

Налаштуйте колірну схему застосунку:

- **Основний колір**, **Акцентний колір**, **Попереджувальний колір** — клацніть поля кольору, щоб відкрити вибір кольору.
- **Назва пресета** — введіть або виберіть назву, щоб зберегти чи завантажити колірний пресет.
- Натисніть **Зберегти**, щоб зберегти поточні кольори як іменований пресет, або **Завантажити**, щоб застосувати збережений пресет.

На мобільних пристроях тут також з’являється **перемикач темного / світлого режиму**.

### Навчальні посібники

Натисніть **Розпочати тур Dino**, щоб перезапустити інтерактивний тур застосунком з початку.

!!! tip "Доступність"
    Цей розділ показано лише тоді, коли інтерактивний тур налаштовано у вашій інсталяції.

### Резервне копіювання та відновлення

*(Лише для адміністраторів, якщо ввімкнено.)*

- **Резервне копіювання даних** — завантажує повний експорт бази даних застосунку у вигляді JSON-файлу.
- **Відновлення даних** — завантажує раніше експортований JSON-файл для відновлення бази даних.

!!! warning "Обережно під час відновлення"
    Відновлення даних замінить поточну базу даних. Цю дію неможливо скасувати.
