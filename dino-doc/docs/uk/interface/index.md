# Навігація та інтерфейс

Інтерфейс Dino складається з верхньої панелі інструментів і меню бічної навігації, які присутні на кожній сторінці після входу в систему.

![Головний вигляд сторінки Main Nav](../imgs/interface/index.png)

---

## Бічна навігація

Бічне меню дає змогу переміщатися між основними розділами застосунку.

**Стандартні розділи** (видимі всім автентифікованим користувачам):

| Розділ | Опис |
|---|---|
| Dashboard | Головний екран. |
| Forms | Форми збору даних і дані. |
| Reports | Згенеровані report. |
| Aggregation | Уніфікований перегляд даних з кількох form. |
| Metrics | Довідкові дані (проєкти, posizioni, організації тощо). *(Приховано для користувачів із гостьовим доступом.)* |
| AI | ШІ-асистент (DinoGPT). |

**Адміністративні розділи** (видимі лише адміністраторам, показані під роздільником):

| Розділ | Опис |
|---|---|
| Users | Облікові записи користувачів і групи дозволів. |
| Languages | Керування перекладом інтерфейсу. |

На великих екранах меню завжди видиме ліворуч. На менших екранах воно згортається, і його можна відкрити за допомогою **кнопки меню** (значок гамбургера) на верхній панелі інструментів. За будь-якого розміру екрана натисніть кнопку меню, щоб розгорнути підписи меню або згорнути їх до самих лише значків.

## Верхня панель інструментів

Панель інструментів угорі екрана містить такі елементи керування, зліва направо:

- **Перемикач меню** — відкриває або згортає бічне меню.
- **Логотип** — відображає логотип вашої організації або Dino.
- **Індикатор нової версії** — значок завантаження з'являється, коли доступна нова версія Dino. Натисніть його, щоб перезавантажити застосунок і застосувати оновлення.
- **DINO-AI Credits** — показує ваш залишок кредитів ШІ у вигляді значка. Натисніть, щоб відкрити [Область користувача](#область-користувача) на панелі Credits. *(Видимо лише за умови налаштування ключа API DINO-AI.)*
- **Перемикач темної / світлої теми** — значок сонця, повзунок і значок місяця. Використовуйте повзунок для перемикання між світлою та темною темами. *(Приховано на мобільних пристроях — натомість скористайтеся Областю користувача.)*
- **Значок інформації** — наведіть курсор, щоб побачити інформацію про версію цієї інсталяції.
- **Значок довідки** — відкриває плейлист із навчальними відео Dino в новій вкладці.
- **Значок налаштувань** — відкриває [Область користувача](#область-користувача).
- **Значок синхронізації** — показує поточний стан синхронізації даних. Натисніть, щоб запустити синхронізацію вручну.
- **Дзвіночок сповіщень** — показує кількість непрочитаних сповіщень у вигляді значка. Дзвіночок дзвенить, коли надходять нові сповіщення. Див. [Сповіщення](#сповіщення) нижче.
- **Вибір мови** — перемикання мови інтерфейсу.
- **Ім'я користувача** — натисніть, щоб відкрити [Область користувача](#область-користувача).
- **Значок виходу** — натисніть, щоб вийти з системи. Значок сірий, поки триває синхронізація або коли пристрій перебуває офлайн; у цих станах вихід недоступний.

## Синхронізація даних

Dino синхронізує ваші дані із сервером у фоновому режимі. **Значок синхронізації** на панелі інструментів показує поточний стан:

| Значок | Значення |
|---|---|
| `sync` (статичний) | Усі дані актуальні. |
| `sync_problem` (пульсує) | У вас є локальні зміни, які ще не синхронізовано. Натисніть, щоб запустити синхронізацію. |
| `sync` (обертається) | Синхронізація триває. |
| `sync_disabled` | Пристрій офлайн; синхронізація недоступна. |
| `sync` зі значком `!` | Виникла проблема із синхронізацією. Перегляньте сповіщення, щоб дізнатися подробиці. |

Коли синхронізація завершується, внизу екрана ненадовго з'являється сповіщення:

- *"Synchronization complete"* — усі дані успішно синхронізовано.
- *"Synchronization complete with errors. Could not synchronize: [items]. Please check your notifications."* — один або кілька наборів даних не вдалося синхронізувати. Також у вашому списку сповіщень створюється сповіщення.

## Сповіщення

Натисніть **значок дзвіночка** на панелі інструментів, щоб відкрити спадне меню сповіщень. Значок на дзвіночку показує кількість непрочитаних повідомлень.

![Спадне меню сповіщень відкрите](../imgs/interface/index-notifications.png)

Зі спадного меню ви можете:

1.  **Натиснути на сповіщення**, щоб позначити його як прочитане.
2.  **Натиснути кнопку зі стрілкою** на сповіщенні (якщо вона є), щоб перейти безпосередньо до відповідного розділу застосунку.
3.  **Позначити все як прочитане** — позначає всі поточні сповіщення як прочитані.
4.  **Переглянути всі сповіщення** — переходить на повну сторінку [Сповіщення](../notifications/index.md).

## Область користувача

Натисніть **значок налаштувань**, своє **ім'я користувача** або **лічильник DINO-AI Credits**, щоб відкрити діалогове вікно Області користувача. Угорі нього показано ваше повне ім'я та адресу електронної пошти.

![Діалогове вікно області користувача відкрите](../imgs/interface/index-user-area.png)

### Зміна пароля

1.  Введіть **поточний пароль**.
2.  Введіть **новий пароль**.
3.  **Підтвердьте новий пароль**.
4.  Натисніть кнопку зі стрілкою, щоб зберегти.

Якщо поточний пароль неправильний або нові паролі не збігаються, з'явиться повідомлення про помилку.

### Ключі API

Перегляньте або задайте свій **ключ API DINO-AI**. Щойно збережено дійсний ключ, він показується в режимі лише для читання. Використовуйте значок ока, щоб показати або приховати ключ, і значок копіювання, щоб скопіювати його до буфера обміну.

### Credits

Показує ваш поточний **залишок кредитів DINO-AI**. Якщо налаштовано інтеграцію з оплатою, доступна кнопка **Add more** для придбання додаткових кредитів.

!!! tip "Видимість"
    Цей розділ видно лише за умови налаштування ключа API DINO-AI.

### Тема DINO

Налаштуйте колірну схему застосунку:

- **Primary color**, **Accent color**, **Warning color** — натисніть на поля кольорів, щоб відкрити вибір кольору.
- **Preset name** — введіть або виберіть назву, щоб зберегти чи завантажити набір кольорів.
- Натисніть **Save**, щоб зберегти поточні кольори як іменований набір, або **Load**, щоб застосувати збережений набір.

На мобільних пристроях тут також з'являється **перемикач темної / світлої теми**.

### Навчальні матеріали

Натисніть **Start Dino Tour**, щоб перезапустити ознайомлювальний тур застосунком із самого початку.

!!! tip "Доступність"
    Цей розділ показується лише за умови налаштування ознайомлювального туру у вашій інсталяції.

### Резервне копіювання та відновлення

*(Лише для адміністраторів, якщо ввімкнено.)*

- **Backup Data** — завантажує повний експорт бази даних застосунку як файл JSON.
- **Restore Data** — завантажує раніше експортований файл JSON для відновлення бази даних.

!!! warning "Обережно з відновленням"
    Відновлення даних замінить поточну базу даних. Цю дію неможливо скасувати.
