# Редагування схеми звіту

Сторінка **Редагування схеми звіту** дозволяє створити нову схему звіту або змінити наявну. Схема звіту визначає структуру, макет і джерела даних для звіту в Dino.

![Main view of the Edit Report Schema page](../imgs/reports/edit-report-schema.png)

На цій сторінці ви налаштовуєте назву звіту, опис і конкретні поля даних, які будуть відображатися у звіті з надісланих форм.

## Створення нової схеми звіту

Щоб створити нову схему звіту:

1. Перейдіть до розділу **Звіти** у головному меню.
2. Натисніть **Створити схему звіту**.
3. Ви потрапите на сторінку "Редагування схеми звіту".
4. Введіть описову **назву** для вашого звіту.
5. (Необов’язково) Додайте **опис**, щоб пояснити призначення звіту.
6. Налаштуйте дані та макет звіту за допомогою доступних опцій.
7. Натисніть **Зберегти**, щоб створити схему.

## Редагування наявної схеми звіту

Щоб змінити раніше створену схему звіту:

1. Перейдіть до розділу **Звіти**.
2. Знайдіть у списку схему звіту, яку потрібно редагувати, і натисніть на неї.
3. Натисніть кнопку **Редагувати** (зазвичай позначена значком олівця).
4. Ви потрапите на сторінку "Редагування схеми звіту" із завантаженою поточною конфігурацією.
5. Внесіть бажані зміни до назви, опису або конфігурації даних.
6. Натисніть **Зберегти**, щоб оновити схему.

!!! tip "Збереження роботи"
    Не забувайте натискати **Зберегти** після внесення змін. Ваші зміни не застосовуються, доки ви не збережете схему.

## Налаштування даних звіту

Основою схеми звіту є визначення того, які дані з надісланих форм будуть відображатися у звіті. Зазвичай ви можете:

* **Вибрати джерело даних:** Виберіть схему форми, яка містить дані, що мають увійти до звіту.
* **Вибрати поля даних:** Виберіть конкретні поля з підключених схем форм, щоб додати їх як стовпці у звіті.
* **Задати відображувані назви:** Налаштуйте заголовки стовпців, які показуються у звіті для кожного вибраного поля.
* **Визначити фільтри:** Задайте умови для включення лише тих надісланих форм, які відповідають вашим критеріям (наприклад, надіслані форми за певний період часу).

!!! warning "Джерело даних"
    Схема звіту має бути підключена щонайменше до однієї схеми форми, щоб мати дані для відображення. Переконайтеся, що відповідна форма існує, перш ніж створювати звіт.

## Наступні кроки

Після збереження схеми звіту ви можете:

* Перейти на сторінку [Звіти](index.md), щоб переглянути та запустити новий звіт.
* Повернутися на цю сторінку, щоб за потреби внести додаткові налаштування.
