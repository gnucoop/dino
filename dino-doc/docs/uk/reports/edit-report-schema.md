# Редагування report schema

Сторінка **Редагування report schema** дає змогу створити новий report schema або змінити наявний. Report schema визначає структуру, макет і джерела даних для report у Dino.

![Головний вигляд сторінки Редагування report schema](../imgs/reports/edit-report-schema.png)

На цій сторінці ви налаштовуєте назву report, опис і конкретні поля даних, які відображатимуться в report з ваших даних форми.

## Створення нового report schema

Щоб створити новий report schema:

1. Перейдіть до розділу **Reports** у головному меню.
2. Натисніть **Створити report schema**.
3. Ви потрапите на сторінку Редагування report schema.
4. Введіть описову **Назву** для вашого report.
5. (Необов'язково) Додайте **Опис**, щоб пояснити призначення report.
6. Імпортуйте файл XLSReport
7. Натисніть **Зберегти**, щоб створити schema.

## Редагування наявного report schema

Щоб змінити report schema, який ви вже створили:

1. Перейдіть до розділу **Reports**.
2. Знайдіть у списку report schema, який бажаєте відредагувати, і натисніть на нього.
3. Натисніть кнопку **Редагувати** (часто позначена значком олівця).
4. Ви потрапите на сторінку Редагування report schema із завантаженою поточною конфігурацією.
5. Внесіть бажані зміни до назви, опису або конфігурації даних.
6. Натисніть **Зберегти**, щоб оновити schema.

!!! tip "Збереження вашої роботи"
    Завжди пам'ятайте про необхідність натиснути **Зберегти** після внесення змін. Ваші зміни не застосовуються, доки ви не збережете schema.

## Налаштування даних report

Основою report schema є визначення того, які дані з ваших даних форми відображатимуться в report. Зазвичай ви можете:

* **Вибрати джерело даних:** Виберіть form schema, який містить потрібні вам дані для report.
* **Вибрати поля даних:** Виберіть конкретні поля з підключених form schema, щоб включити їх як стовпці в report.
* **Задати відображувані назви:** Налаштуйте заголовок стовпця, який відображається в report для кожного вибраного поля.
* **Визначити фільтри:** Задайте умови, щоб включити лише конкретні дані, які відповідають вашим критеріям (наприклад, дані за певний діапазон дат).

!!! warning "Джерело даних"
    Report schema має бути підключений принаймні до одного form schema, щоб мати дані для відображення. Переконайтеся, що відповідний form існує, перш ніж створювати report.
