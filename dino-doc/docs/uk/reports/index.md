# Звіти

Розділ «Звіти» — це ваш центр доступу до всіх доступних report schema. Report schema визначає структуру та вміст звіту, який можна згенерувати з ваших зібраних даних. Тут ви можете переглядати report schema та отримувати доступ до звітів, які вже створені для кожного з них.

![Головний вигляд сторінки «Звіти»](../imgs/reports/index.png)

Report schema створюються з формату на основі Excel під назвою [XLSReport](xlsreport.md) або генеруються автоматично з form schema (див. [Автоматичні звіти](autoreports.md)). Щоб створити report schema з файлу, спочатку підготуйте файл XLSReport, а потім імпортуйте його в Dino. Повну процедуру описано в розділі [Редагувати report schema](edit-report-schema.md).

---

## Перегляд report schema

Коли ви відкриваєте сторінку «Звіти», ви бачите картку для кожного report schema, до якого маєте доступ. Картки відсортовано за алфавітом за назвою report schema.

Щоб знайти потрібний report schema:

1. Скористайтеся полем **Фільтр** угорі сторінки.
2. Введіть будь-яку частину назви або мітки report schema.
3. Список фільтрується під час введення, показуючи лише відповідні report schema.

Щоб відкрити звіти певного report schema, натисніть будь-де на його картці.

На кожній картці, яку можна редагувати, іконки в правому верхньому куті дають змогу керувати report schema безпосередньо:

- **Редагувати** (іконка олівця) — відкриває report schema для редагування. Див. [Редагувати report schema](edit-report-schema.md).
- **Видалити** (іконка кошика) — видаляє report schema після підтвердження. Report schema, для якого ще є звіти, видалити не можна: спочатку видаліть його звіти.

Іконка відбитка на картці означає, що report schema є *унікальним*: він може створити лише один звіт для заданого точного набору метрик. Якщо ви спробуєте створити звіт, який уже існує для цих метрик, Dino не створить дублікат.

!!! tip "Ще немає report schema?"
    Якщо ви бачите повідомлення «There are not any Reports currently available», це означає, що жодного report schema ще не створено або не надано вам. Попросіть свого адміністратора Dino створити його або додайте його самостійно, якщо маєте відповідні права.

## Додавання нового report schema

Ви можете почати створення нового report schema з головної сторінки «Звіти».

1. Натисніть кнопку **+** (*Add new Reports schema*) у правому нижньому куті екрана. Вона показується лише за наявності дозволу на створення report schema.
2. Виконайте кроки, описані в розділі [Редагувати report schema](edit-report-schema.md).

---

## Відкриття звітів report schema

Натискання на картку report schema переносить вас до списку звітів, згенерованих із цього report schema. Звідти ви можете:

1. Переглянути наявні звіти в таблиці з такими подробицями, як користувач, який створив звіт, назва звіту та зібраний діапазон дат.
2. Відфільтрувати та знайти потрібні звіти в списку. Скористайтеся пошуком за ключовими словами, полями діапазону дат і кнопкою **Фільтри** для складніших умов. Ви також можете зберегти набір фільтрів як шаблон і застосувати його пізніше.
3. Відкрити звіт для перегляду: наведіть курсор на його рядок і натисніть іконку **Перегляд** (око) або виберіть рядок і натисніть **Перегляд** на панелі дій над таблицею. Див. [Редагувати звіт](edit-report.md).
4. Видалити звіт, який більше не потрібен: виберіть його рядок, а потім натисніть **Видалити** на панелі дій.

Щоб створити новий звіт із вибраного report schema, натисніть **Додати новий звіт** над таблицею. Звіти, які використовують підказки ШІ, споживають токени DINO-AI. Кількість токенів, яку використає звіт, показано поруч із кнопкою, тож ви завжди знаєте вартість, перш ніж почати.

!!! warning "Недостатньо токенів"
    Якщо на вашому акаунті недостатньо токенів DINO-AI, Dino не запустить звіт і покаже повідомлення з проханням додати токени. Додайте токени на свій акаунт і спробуйте знову.

## Що можна зробити далі

З розділу «Звіти» ви можете перейти до таких завдань:

* **[Редагувати звіт](edit-report.md)** — Перегляньте звіт і експортуйте його.
* **[Редагувати report schema](edit-report-schema.md)** — Створюйте нові report schema або редагуйте наявні, щоб визначити, що з'являється у ваших звітах. Зазвичай для цього потрібні права адміністратора.
* **[Агрегація](../aggregation/index.md)** — Перегляньте дані всіх ваших form schema в одному списку.
