# Звіти

Розділ Звіти — це ваш центр доступу до всіх доступних report schema. Report schema визначає структуру та вміст звіту, який можна сформувати з ваших зібраних даних. Тут ви можете переглядати report schema та отримувати доступ до вже створених звітів.

![Головний вигляд сторінки Звіти](../imgs/reports/index.png)

Звіти можна створювати лише за допомогою форми на основі Excel під назвою [XLSReport](xlsreport.md). Щоб створити новий звіт, спершу потрібно створити файл XLSReport, а потім імпортувати його в Dino згідно з процедурою, описаною нижче.

---

## Перегляд report schema

Коли ви відкриваєте сторінку Звіти, ви бачите список усіх report schema, до яких у вас є доступ. Список відсортовано за алфавітом за назвою report schema.

Щоб знайти потрібний report schema:

1. Скористайтеся рядком пошуку вгорі сторінки.
2. Введіть будь-яку частину назви або мітки report schema.
3. Список фільтруватиметься в реальному часі, показуючи лише відповідні report schema.

Щоб переглянути звіти для певного report schema, натисніть на його картку в списку.

!!! tip "Початок роботи"
    Якщо ви бачите повідомлення "There are no reports", це означає, що report schema ще не створено або не надано вам доступ. Зверніться до адміністратора Dino, щоб розпочати роботу.

---

## Створення нового report schema

Ви можете розпочати процес генерації нового report schema безпосередньо з головної сторінки Звіти. Натисніть кнопку **+** (плюс) у правому нижньому куті екрана.

Детальні кроки дивіться в посібнику [Редагувати звіт](edit-report.md).

---

## Що ви можете робити

З головної сторінки Звіти ви можете перейти до виконання цих основних дій:

* **[Редагувати звіт](edit-report.md)** — Сформуйте новий документ звіту, вибравши report schema, обравши свої метрики та встановивши діапазон дат.
* **[Редагувати report schema](edit-report-schema.md)** — Створюйте нові report schema або редагуйте наявні, щоб визначити, які дані відображаються у звітах. Зазвичай це потребує прав адміністратора.
