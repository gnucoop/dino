# Редагування даних форми

Екран редагування форми дає змогу змінювати наявні дані форми. Ви можете оновлювати дані, додавати нову інформацію або зберігати зміни як чернетку, щоб завершити пізніше.

Коли ви відкриваєте дані форми для редагування, ви бачите той самий інтерфейс форми, що й під час введення даних, але всі раніше збережені дані вже заповнено.

![Головний вигляд сторінки редагування форми](../imgs/forms/edit-form.png)

## Як редагувати дані

1.  Перейдіть до списку даних для вашої форми.
2.  Знайдіть конкретні дані, які хочете відредагувати.
3.  Натисніть кнопку **Редагувати** (зазвичай позначена значком олівця) для цих даних. Форма відкриється в режимі редагування.
4.  Внесіть потрібні зміни до будь-якого поля форми.
5.  Виберіть дію внизу форми:
    *   **Зберегти чернетку**: зберігає поточні зміни без надсилання форми. Ви можете повернутися й відредагувати її знову пізніше.
    *   **Надіслати**: зберігає всі зміни та надсилає оновлені дані форми.

!!! tip "Відстеження змін"
    Dino автоматично фіксує зміни, які ви вносите між початковими даними та відредагованою версією. Так створюється історія того, хто, що і коли змінив.
