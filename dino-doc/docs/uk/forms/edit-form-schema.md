# Редагування схеми форми

Сторінка редагування схеми форми дозволяє створити нову схему або змінити існуючу. Тут ви визначаєте основні атрибути форми, керуєте статусами та метриками, контролюєте видимість і пов'язуєте схему з іншими формами через зв'язки.

Ви можете потрапити на цю сторінку:

- Натиснувши **Створити** на [огляді форм](index.md), щоб створити нову схему.
- Вибравши **Редагувати** на картці існуючої схеми або з її детального перегляду.

Навігаційні хлібні крихти зверху показують ваше поточне розташування (наприклад, **Форми > Моє опитування > Редагувати**).

![Main view of the Edit Form Schema page](../imgs/forms/edit-form-schema.png)

## Атрибути форми

Заповніть або відредагуйте наступні поля:

| Поле | Опис |
|------|------|
| **Назва форми** | Унікальний системний ідентифікатор (наприклад, `survey_2025`). Dino попереджає, якщо назва вже зайнята. |
| **Позначка форми** | Людиночитана назва, що відображається у списках і звітах. |
| **Набір іконок** | Виберіть **Стандартний** (матеріальні іконки) або **Гуманітарний** (користувацькі SVG іконки). |
| **Ідентифікатор іконки** | Виберіть іконку зі списку автодоповнення. Попередній перегляд оновлюється в реальному часі. |
| **Статуси форми** | Одна або кілька міток, що описують стан подання (наприклад, Чернетка, Схвалено, Відхилено). Виберіть існуючі статуси або **Створити новий статус**, щоб додати на льоту. |
| **Метрики форми** | Метрики для збору кожного подання. Виберіть одну або декілька зі списку. |
| **Видимість** | **Приватна** – лише учасники призначених груп можуть бачити форму. **Публічна** – будь-хто з посиланням може переглядати та надсилати. |
| **Поведінка набору метрик** | **Стандартна** – кожне значення метрики може з'являтися декілька разів у різних поданнях. **Унікальна** – значення метрики (наприклад, назва району) можна використати лише один раз на форму. |
| **Генерувати звіт** | Коли **Так**, Dino автоматично генерує звіт після кожного подання. Цей параметр прихований, якщо автоматичний звіт уже налаштовано. |

!!! warning "Унікальна поведінка набору метрик"
    Використовуйте **Унікальну** з обережністю — коли значення використане для метрики, його не можна повторно використати в іншому поданні тієї ж форми.

## Керування статусами форми

1. Натисніть поле **Статуси форми**, щоб розгорнути список.
2. Щоб додати існуючий статус, позначте його прапорець.
3. Щоб створити новий статус, натисніть **Створити новий статус**. Відкриється діалог, де можна ввести мітку, вибрати колір і зберегти.
4. Щоб відредагувати існуючий статус, натисніть піктограму **редагування** (олівець) біля нього.
5. Натисніть за межами випадаючого списку, щоб закрити його.

## Визначення зв'язків

Зв'язки дозволяють пов'язувати поля різних схем форм (наприклад, підформу, яка залежить від вибору в основній формі).

1. Натисніть кнопку **Зв'язки**.
2. У діалоговому вікні додавайте, редагуйте або видаляйте з'єднання між схемами.

![Form relationships (dependencies) editor dialog](../imgs/forms/edit-form-schema-relationships.png)

!!! tip "Зв'язки доступні лише під час редагування існуючої схеми, а не під час початкового створення."

## Збереження та імпорт

- **Зберегти** – зберігає всі зміни. Кнопка неактивна, якщо форма недійсна або ще зберігається.
- **Імпортувати** – відкриває вибір файлу для завантаження схеми форми з файлу JSON або CSV. Використовуйте це, щоб повторно використати структуру схеми з іншого проєкту.
