# Редагування схеми форми

Сторінка «Редагування схеми форми» дає змогу створювати нову схему форми або змінювати наявну. Тут ви визначаєте основні атрибути форми, керуєте її статусами та метриками, контролюєте видимість і пов’язуєте схему з іншими формами через зв’язки.

Ви можете перейти на цю сторінку:

- Натисніть **Створити** на сторінці [Огляд форм](index.md), щоб створити нову схему.
- Виберіть **Редагувати** на картці наявної схеми або в її детальному перегляді.

Хлібні крихти вгорі показують ваше поточне розташування (наприклад, **Форми > Моє опитування > Редагування**).

![Головний вигляд сторінки редагування схеми форми](../imgs/forms/edit-form-schema.png)

## Атрибути форми

Заповніть або відкоригуйте наступні поля:

| Поле | Опис |
|-------|-------------|
| **Назва форми** | Унікальний системний ідентифікатор (наприклад, `survey_2025`). Dino попереджає, якщо назва вже зайнята. |
| **Підпис форми** | Зрозуміла назва, яка відображається у списках і звітах. |
| **Набір іконок** | Виберіть **За замовчуванням** (іконки Material) або **Гуманітарний** (користувацькі SVG-іконки). |
| **Ідентифікатор іконки** | Виберіть іконку зі списку автодоповнення. Попередній перегляд оновлюється в реальному часі. |
| **Статуси форми** | Одна або кілька позначок, які описують стан подання (наприклад, Чернетка, Затверджено, Відхилено). Виберіть наявні статуси або **Створити новий статус**, щоб додати його на льоту. |
| **Метрики форми** | Метрики, які потрібно збирати для кожного подання. Виберіть одну або кілька зі списку. |
| **Видимість** | **Приватна** – лише учасники призначених груп можуть бачити форму. **Публічна** – будь-хто за посиланням може переглядати й надсилати. |
| **Поведінка набору метрик** | **За замовчуванням** – кожне значення метрики може з’являтися кілька разів у різних поданнях. **Унікальне** – значення метрики (наприклад, назва району) можна використати лише один раз для форми. |
| **Генерувати звіт** | **Так** – Dino автоматично створює звіт після кожного подання. Цей параметр приховано, якщо автоматичний звіт уже налаштовано. |

!!! warning "Унікальна поведінка набору метрик"
    Використовуйте **Унікальне** обережно — щойно значення використано для метрики, його не можна повторно використати в іншому поданні тієї самої форми.

## Керування статусами форми

1. Натисніть поле **Статуси форми**, щоб розгорнути список.
2. Щоб додати наявний статус, позначте його прапорець.
3. Щоб створити новий статус, натисніть **Створити новий статус**. Відкриється діалог, де ви можете ввести позначку, обрати колір і зберегти.
4. Щоб редагувати наявний статус, натисніть іконку **редагування** (олівець) поруч із ним.
5. Натисніть поза межами розкривного списку, щоб закрити його.

## Визначення зв’язків

Зв’язки дають змогу пов’язувати поля між різними схемами форм (наприклад, підформу, яка залежить від вибору в головній формі).

1. Натисніть кнопку **Зв’язки**.
2. У діалозі додавайте, редагуйте або видаляйте зв’язки між схемами.

![Діалог редактора зв’язків (залежностей) форми](../imgs/forms/edit-form-schema-relationships.png)

!!! tip "Зв’язки доступні лише під час редагування наявної схеми, а не під час первинного створення."

## Збереження та імпорт

- **Зберегти** – зберігає всі зміни. Кнопка недоступна, якщо форма некоректна або ще зберігається.
- **Імпорт** – відкриває діалог вибору файлу, щоб завантажити схему форми з JSON або CSV-файлу. Використовуйте це, щоб повторно використати структуру схеми з іншого проєкту.

## Конструктор форм

Нижче атрибутів область **Конструктор форм** дає змогу перетягувати, розміщувати та налаштовувати окремі поля (запитання, розділи тощо). Зміни одразу відображаються в попередньому перегляді в правій частині конструктора.
