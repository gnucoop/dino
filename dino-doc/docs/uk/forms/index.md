# Форми

Сторінка **Форми** є вашим центральним хабом для всього структурованого збору даних у Dino. Тут ви можете керувати схемами форм, переглядати та редагувати подання, а також виконувати масові дії з вашими даними.

![Main view of the Forms page](../imgs/forms/index.png)

## Сітка схем форм

Коли ви вперше відкриваєте сторінку Форми, ви бачите сітку всіх доступних схем форм. Кожна плитка відображає назву схеми та іконку. Наведіть курсор на плитку, щоб побачити кнопки дій:

- **Редагувати схему** — Відкриває редактор схем для зміни структури форми.
- **Видалити схему** — Видаляє схему та всі її подання.
- **Поділитися публічним посиланням** — Генерує публічне посилання на схему для зовнішнього збору даних.
- **Переглянути мапу** — Відкриває [Мапу форм](forms-map.md) з геолокаційними поданнями.
- **Чат з вашими даними** — Запускає [DataChat](datachat.md) для постановки запитань щодо подань.

Натисніть на плитку, щоб відкрити список подань для цієї схеми.

!!! tip "Скористайтеся рядком фільтра"
    У верхній частині сторінки ви можете фільтрувати схеми за ключовим словом. Сітка оновлюється автоматично.

## Список подань

Після вибору схеми форми ви потрапляєте до деталізованого подання списку. Ця таблиця показує всі подання (записи) для цієї схеми. Кожен рядок відображає ключові поля, включаючи статус (якщо визначено) та будь-які власні метрики.

![Список подань для схеми форми](../imgs/forms/index-list.png)

З цього списку ви можете:

- **Додати нове подання** — Натисніть плаваючу кнопку **+** (внизу праворуч), щоб відкрити порожню форму.
- **Редагувати існуюче подання** — Натисніть іконку **редагування** у рядку.
- **Переглянути деталі подання** — Натисніть іконку **перегляду**.
- **Видалити подання** — Натисніть іконку **видалення**.
- **Надрукувати або завантажити** PDF або DOCX подання.
- **Надрукувати бейдж** (якщо активна метрика справи).
- **Розгорнути рядок**, щоб побачити вкладені деталі (якщо налаштовано).

### Фільтрація та пошук

Використовуйте панель фільтрів, що розгортається, у верхній частині списку:

- **Пошук за ключовим словом** — Знайдіть подання за будь-яким текстом.
- **Діапазон дат** — Фільтруйте за датою створення.
- **Фільтри метрик** — Звужте пошук за місцезнаходженням, проектом, територією, справою, організацією або іншими власними метриками.
- **Фільтр статусу** — Фільтруйте за статусом форми (наприклад, Схвалено, Очікує).
- **Фільтр користувача** — Показувати лише подання, створені певним користувачем.

Ви можете зберігати та завантажувати пресети фільтрів за допомогою **менеджера пресетів**.

### Масові дії

Виберіть декілька рядків за допомогою прапорців. Потім виконайте масові операції:

- **Видалити** — Видалити вибрані подання.
- **Масове редагування** — Змінити поле у всіх вибраних поданнях.

### Експорт та імпорт

![Export dialog for downloading form submissions](../imgs/forms/index-export.png)

Натисніть кнопку **експорту** (іконка завантаження хмари), щоб відкрити діалог експорту. Виберіть формат CSV або XLSX та завантажте всі відфільтровані подання.

![Import dialog for uploading multiple submissions from a file](../imgs/forms/index-import.png)

Якщо з'являється кнопка **імпорту** (іконка завантаження хмари), ви можете завантажити файл (CSV або XLSX), щоб додати одразу кілька подань.

!!! warning "Дозволи"
    Деякі дії (редагування схеми, видалення, експорт, імпорт) доступні лише за наявності відповідних дозволів. Зверніться до адміністратора, щоб запросити доступ.
