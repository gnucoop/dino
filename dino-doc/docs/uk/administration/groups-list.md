# Перелік груп

Сторінка «Перелік груп» відображає всі групи користувачів у вашому екземплярі Dino. Звідси ви можете переглядати, фільтрувати та створювати нові групи, або редагувати наявні.

![Main view of the Groups List page](../imgs/administration/groups-list.png)

## Що ви бачите

Сторінка містить:

- **Панель пошуку та фільтрів** – Використовуйте доступні фільтри, щоб звузити список груп. Фільтри включають: Проєкт, Місцезнаходження, Зона, Кейс та Організація. Також можна скористатися загальним рядком пошуку для пошуку груп за назвою.
- **Таблиця даних** – Показує ключову інформацію про кожну групу, включаючи назву групи. Додаткові стовпці (ID, дата створення) приховано за замовчуванням, але їх можна зробити видимими через вибір стовпців.
- **Плаваюча кнопка дії** – Кнопка «+» у правому нижньому куті відкриває редактор для створення нової групи.
- **Дії з рядком** – Натисніть на рядок, щоб відобразити вбудовані параметри для вибору або розгортання детальнішої інформації про цю групу.

## Використання фільтрів

1. Натисніть значок фільтра, щоб відкрити панель фільтрів.
2. Виберіть тип фільтра зі спадного списку (наприклад, **Проєкт**).
3. Виберіть або введіть значення, за яким потрібно фільтрувати.
4. Список автоматично оновлюється, показуючи лише групи, що відповідають критеріям.

!!! tip "Декілька фільтрів"
    Ви можете застосувати кілька фільтрів одночасно, щоб ще більше звузити результати.

## Створення нової групи

1. Натисніть плаваючу кнопку **+** у правому нижньому куті сторінки.
2. Відкриється редактор груп. Введіть необхідні дані:
   - **Назва групи** – унікальна назва групи.
3. За бажанням призначте користувачів до групи (див. [Перелік користувачів](users-list.md) для керування окремими користувачами).
4. Натисніть **Зберегти**, щоб створити групу. Вона одразу з'явиться у списку.

## Редагування або перегляд групи

- **Натисніть у будь-якому місці рядка**, щоб розгорнути або вибрати групу. Доступні дії залежать від ваших прав.
- Щоб відкрити повний редактор для групи, натисніть значок редагування (олівець), який з'являється на рядку.
- Ви можете змінити назву групи та її учасників.

!!! warning "Видалення груп"
    Видалення групи видаляє всіх її учасників з групи. Цю дію неможливо скасувати. Видаляйте через значок видалення (смітник) на рядку після розгортання або вибору рядка.
