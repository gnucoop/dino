# Керування мовами

Сторінка **Мови** дозволяє адміністраторам керувати всім перекладеним текстом, що використовується в Dino. Тут ви можете переглядати, редагувати та додавати переклади, керувати доступними мовами, а також експортувати файли перекладів для резервного копіювання чи редагування.

    Ця область видима лише користувачам із роллю адміністратора. Якщо ви не бачите її в навігації, зверніться до системного адміністратора.

## Перегляд перекладів

Основне подання показує список усіх записів перекладів. Кожен запис відображає **ключ** — внутрішній ідентифікатор, який використовує застосунок, — а коли вибрано мову, також відповідний перекладений текст.

Під час завантаження даних перекладів відображається індикатор завантаження.

### Фільтрування списку

Два елементи керування у верхній частині сторінки дають змогу звузити список записів:

- **Пошук за ключовим словом** — введіть будь-яке слово, щоб відфільтрувати записи, у яких ключ або переклад містить цей текст. Список оновлюється під час введення.
- **Вибір мови** — рядок кнопок показує **Ключ** та по одній кнопці для кожної доступної мови. Натисніть назву мови, щоб показати переклади цієї мови поруч із кожним ключем. Записи без перекладу для вибраної мови відображаються як *(Немає перекладу)*.

---

## Редагування запису перекладу

1. Натисніть будь-який запис у списку, щоб відкрити діалог **Редагування перекладу**.
2. У діалозі відображаються **ключ** та текстове поле для кожної доступної мови.
3. Оновіть переклади за потреби.
4. Натисніть **Зберегти**, щоб застосувати зміни, або **Скасувати**, щоб закрити без збереження.

Ви також можете остаточно видалити окремий запис із цього діалогу, натиснувши кнопку **Видалити**. Це видаляє ключ перекладу та всі пов’язані з ним переклади.

!!! warning
    Видалення запису перекладу є остаточним. Ключ і всі його значення для мов буде видалено.

## Додавання нового запису перекладу

Використовуйте це, коли потрібно додати ключ перекладу, якого ще немає в системі.

1. Натисніть кнопку **+ Переклад** на панелі інструментів.
2. Відкриється діалог **Додати переклад**. Він містить текстове поле для кожної активної мови.
3. Введіть текст перекладу для кожної мови за потреби.
4. Натисніть **Зберегти**, щоб додати новий запис, або **Скасувати**, щоб скасувати.

Після збереження запису на короткий час з’явиться повідомлення підтвердження.

## Керування мовами

Використовуйте це, щоб додати нову мову, оновити переклади наявної мови або видалити власний набір перекладів.

1. Натисніть кнопку **Мова** на панелі інструментів.
2. Відкриється діалог **Налаштування мов**. Він показує список доступних мов і надає такі дії:
   - **Кнопка +**, щоб додати нову мову.
   - Натисніть назву мови у списку, щоб вибрати її та переглянути попередній перегляд її перекладів.
   - **Оновити переклад** (із вибраною мовою), щоб завантажити новий JSON-файл.
   - **Видалити власний переклад**, щоб видалити дані власного перекладу для вибраної мови.

### Додавання нової мови

1. Натисніть **кнопку +** у верхній частині діалогу.
2. З’явиться форма із запитом на **назву мови** (ім’я, яке відображатиметься в інтерфейсі, наприклад «French» або «fr»).
3. За бажанням завантажте **JSON-файл перекладу**, натиснувши **Додати JSON** і вибравши файл на своєму пристрої. Вміст файлу буде показано для попереднього перегляду перед збереженням.
4. Натисніть **Зберегти**, щоб додати мову, або **Скасувати**, щоб скасувати.

### Перегляд наявної мови

Натисніть кнопку з назвою мови, щоб вибрати її. У діалозі з’явиться попередній перегляд усіх ключів перекладу та значень, які зараз зберігаються для цієї мови.

### Оновлення перекладів мови

Якщо мову вибрано, натисніть **Оновити переклад**, щоб завантажити новий JSON-файл. Діалог покаже попередній перегляд змін — додані нові ключі та змінені ключі — перед збереженням.

1. Натисніть **Оновити переклад** і виберіть JSON-файл на своєму пристрої.
2. Перегляньте попередній перегляд із доданими та зміненими рядками.
3. Натисніть **Зберегти**, щоб застосувати оновлення, або **Скасувати**, щоб скасувати.

### Видалення власного перекладу

Якщо мову вибрано, натисніть **Видалити власний переклад**, щоб видалити дані власного перекладу для цієї мови.

!!! warning
    Це видаляє власні переклади для вибраної мови. Сама мова може залишитися в системі, але її налаштований вміст буде втрачено.

## Експорт перекладів

Ви можете завантажити дані перекладу для будь-якої мови у вигляді JSON-файлу.

1. Натисніть кнопку **Експорт** (значок завантаження) на панелі інструментів.
2. Відкриється діалог **Експорт** зі списком доступних мов.
3. Натисніть назву мови, яку потрібно експортувати. Праворуч з’явиться попередній перегляд її даних перекладу.
4. Натисніть **Завантажити**, щоб зберегти файл на свій пристрій.
