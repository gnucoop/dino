# Керування мовами

Сторінка **Мови** дає змогу адміністраторам керувати всім перекладеним текстом, який використовується в Dino. Тут ви можете переглядати, редагувати та додавати переклади, керувати доступними мовами й експортувати файли перекладів для резервного копіювання чи редагування.

![Головний вигляд сторінки "Мови"](../imgs/administration/languages.png)

!!! warning "Лише для адміністраторів"
    Ця область видима лише користувачам із роллю адміністратора. Якщо ви не бачите її в навігації, зверніться до системного адміністратора.

---

## Перегляд перекладів

Головний вигляд показує список усіх записів перекладів. Кожен запис відображає свій **ключ** — внутрішній ідентифікатор, який використовує застосунок — а також, коли вибрано мову, відповідний перекладений текст.

Під час завантаження даних перекладів відображається індикатор завантаження.

### Фільтрування списку

Два елементи керування вгорі сторінки дають змогу звузити список показаних записів:

- **Пошук за ключовим словом** — введіть будь-яке слово, щоб відфільтрувати записи, ключ або переклад яких містить цей текст. Список оновлюється під час введення.
- **Вибір мови** — рядок кнопок показує **Ключ** і по одній кнопці для кожної доступної мови. Натисніть назву мови, щоб відобразити переклади цією мовою поруч із кожним ключем. Записи без перекладу для вибраної мови показуються як *(Немає перекладу)*.

---

## Редагування запису перекладу

1. Натисніть будь-який запис у списку, щоб відкрити діалог **Редагувати переклад**.
2. Діалог показує **ключ** і текстове поле для кожної доступної мови.
3. За потреби оновіть переклади.
4. Натисніть **Зберегти**, щоб застосувати зміни, або **Скасувати**, щоб закрити без збереження.

У цьому діалозі також можна остаточно видалити окремий запис, натиснувши кнопку **Видалити**. Це видаляє ключ перекладу та всі пов'язані з ним переклади.

!!! warning
    Видалення запису перекладу є незворотним. Ключ і всі його значення для мов буде видалено.

## Додавання нового запису перекладу

Скористайтеся цим, коли потрібно додати ключ перекладу, якого ще немає в системі.

1. Натисніть кнопку **+ Переклад** на панелі інструментів.
2. Відкриється діалог **Додати переклад**. Він містить одне текстове поле для кожної наразі активної мови.
3. За потреби введіть текст перекладу для кожної мови.
4. Натисніть **Зберегти**, щоб додати новий запис, або **Скасувати**, щоб скасувати дію.

Після збереження запису ненадовго з'явиться підтверджувальне повідомлення.

## Керування мовами

Скористайтеся цим, щоб додати нову мову, оновити переклади наявної мови або видалити власний набір перекладів.

1. Натисніть кнопку **Мова** на панелі інструментів.
2. Відкриється діалог **Налаштування мов**. Він показує список доступних мов і надає такі дії:
   - **Кнопка +** для додавання нової мови.
   - Натисніть назву мови у списку, щоб вибрати її та переглянути попередній перегляд її перекладів.
   - **Оновити переклад** (коли вибрано мову), щоб завантажити новий файл JSON.
   - **Видалити власний переклад**, щоб видалити дані власного перекладу для вибраної мови.

### Додавання нової мови

1. Натисніть **кнопку +** вгорі діалогу.
2. З'явиться форма із запитом **назви мови** (назва, яка відображатиметься в інтерфейсі, наприклад "French" або "fr").
3. За бажанням завантажте **файл перекладу JSON**, натиснувши **Додати JSON** і вибравши файл на своєму пристрої. Вміст файлу буде показано в попередньому перегляді перед збереженням.
4. Натисніть **Зберегти**, щоб додати мову, або **Скасувати**, щоб скасувати дію.

### Перегляд наявної мови

Натисніть кнопку з назвою мови, щоб вибрати її. Діалог покаже попередній перегляд усіх ключів і значень перекладів, наразі збережених для цієї мови.

### Оновлення перекладів мови

Коли мову вибрано, натисніть **Оновити переклад**, щоб завантажити новий файл JSON. Перед збереженням діалог покаже попередній перегляд змін — доданих і змінених ключів.

1. Натисніть **Оновити переклад** і виберіть файл JSON на своєму пристрої.
2. Перегляньте попередній перегляд із доданими та зміненими рядками.
3. Натисніть **Зберегти**, щоб застосувати оновлення, або **Скасувати**, щоб скасувати дію.

### Видалення власного перекладу

Коли мову вибрано, натисніть **Видалити власний переклад**, щоб видалити дані власного перекладу для цієї мови.

!!! warning
    Це видаляє власні переклади для вибраної мови. Сама мова може залишитися в системі, але її налаштований вміст буде втрачено.

## Експорт перекладів

Ви можете завантажити дані перекладів для будь-якої мови як файл JSON.

1. Натисніть кнопку **Експорт** (значок завантаження) на панелі інструментів.
2. Відкриється діалог **Експорт** зі списком доступних мов.
3. Натисніть назву мови, яку потрібно експортувати. Праворуч з'явиться попередній перегляд її даних перекладу.
4. Натисніть **Завантажити**, щоб зберегти файл на своєму пристрої.
