# Агрегація

Сторінка «Агрегація» надає єдиний перегляд усіх надісланих форм у вашій організації. Замість того щоб переглядати надіслані форми для однієї схеми, ви можете бачити записи з різних схем разом в одному списку, який можна фільтрувати.

![Головний вигляд сторінки Агрегація](../imgs/aggregation/index.png)

## Перегляд списку

У списку відображаються всі надіслані форми, до яких ви маєте доступ. Кожен рядок представляє одну надіслану форму. За замовчуванням показано такі стовпці:

*   **Схема форми**: назва схеми форми, до якої належить ця надіслана форма.
*   **Статус**: поточний статус робочого процесу надісланої форми.
*   Додаткові стовпці для метрик, як-от **Проєкт**, **Місцезнаходження** або **Організація**, також можуть відображатися залежно від конфігурації вашої системи.

Ви можете натиснути на будь-який рядок, щоб вибрати його або розгорнути для перегляду додаткових деталей.

## Фільтрація списку

Над списком розташована панель фільтрів. Використовуйте її, щоб звузити показ надісланих форм. Ви можете фільтрувати за:

*   Проєктом
*   Місцезнаходженням
*   Територією
*   Справою
*   Кодом справи
*   Організацією
*   Статусом форми
*   Користувачем

!!! tip "Поради щодо фільтрації"
    Панель фільтрів Агрегації призначена для швидкого фільтрування між схемами. Для розширених можливостей, таких як збережені набори фільтрів або експорт даних, перейдіть на [сторінку надісланих форм для конкретної схеми форми](../forms/index.md).

## Дії з рядком

Коли ви наводите курсор на рядок, праворуч з’являється набір іконок дій. Доступні дії для конкретної надісланої форми залежать від ваших дозволів для її схеми форми.

*   **Переглянути**: відкрити надіслану форму в режимі читання.
*   **Редагувати**: відкрити надіслану форму для редагування.
*   **Друкувати**: створити та відкрити PDF-версію надісланої форми. Перед створенням PDF буде запропоновано підтвердити дію.
*   **Видалити**: назавжди видалити надіслану форму. Перед виконанням цієї дії буде запропоновано підтвердити.

## Створення нової надісланої форми

Ви можете розпочати заповнення нової форми безпосередньо зі сторінки «Агрегація».

1.  Натисніть кнопку **+** (Додати) у нижньому правому куті екрана.
2.  Відкриється діалог зі списком схем форм, для яких ви маєте дозвіл створювати надіслані форми.
3.  Виберіть потрібну схему форми зі списку.
4.  Натисніть **Створити форму**. Ви перейдете до форми, щоб почати її заповнення.
