# Datachat

La page Datachat donne accès à **DinoGPT**, un assistant alimenté par l'IA qui peut répondre à des questions sur les données collectées dans vos formulaires. Vous pouvez poser des questions en langage naturel pour obtenir des informations à partir de vos soumissions.

Lorsque vous ouvrez la page Datachat, vous verrez l'interface DinoGPT ainsi qu'un accord sur les conditions d'utilisation. Vous devez lire et accepter ces conditions avant de pouvoir démarrer une session de chat.

!!! warning "Informations générées par l'IA"
    DinoGPT génère des réponses basées sur les données spécifiques de la base de données de votre formulaire. Ses connaissances se limitent à ces données et peuvent ne pas être complètes, exactes ou à jour. Il vous incombe de vérifier toute information fournie. DinoGPT ne fournit pas de conseils professionnels.

## Accepter les conditions d'utilisation

Avant de pouvoir utiliser DinoGPT, vous devez lire et accepter ses conditions d'utilisation.

1.  Lisez attentivement les **Conditions d'utilisation de DinoGPT** affichées sur la page.
2.  Si vous acceptez toutes les conditions, procédez pour démarrer une session de chat.

## Démarrer une session de chat

Pour commencer à poser des questions sur vos données :

1.  Après avoir accepté les conditions, l'interface principale du chat devient active.
2.  Saisissez votre question sur les données du formulaire dans le champ de saisie.
3.  Appuyez sur **Entrée** ou cliquez sur le bouton d'envoi pour soumettre votre question.

L'assistant IA traitera votre question et fournira une réponse basée sur les données de soumission disponibles.

!!! tip "Questions efficaces"
    Pour de meilleurs résultats, posez des questions claires et spécifiques sur les données. Par exemple : « Quelle est l'âge moyen des répondants ? » ou « Liste toutes les soumissions de la semaine dernière. »

## Pendant un chat

- Vous pouvez poser des questions de suivi dans la même session ; DinoGPT conservera le contexte de votre conversation.
- L'historique du chat est visible, ce qui vous permet de revoir les questions et réponses précédentes.

## Mettre fin à une session de chat

Votre session de chat se termine automatiquement lorsque vous quittez la page Datachat. Vous pouvez passer à d'autres pages, comme la [liste des formulaires](index.md), et revenir plus tard pour démarrer une nouvelle session.

!!! warning "Confidentialité des données"
    DinoGPT accède uniquement aux données du schéma du formulaire actuel. Il ne peut pas voir les données d'autres formulaires ni de sources externes.
