# Modifier une soumission de formulaire

L'écran Modifier le formulaire vous permet de modifier une soumission de formulaire existante. Vous pouvez mettre à jour les données, ajouter de nouvelles informations ou enregistrer vos modifications sous forme de brouillon pour les terminer plus tard.

Lorsque vous ouvrez une soumission de formulaire pour la modifier, vous retrouvez la même interface de formulaire que celle utilisée pour la saisie des données, mais avec toutes les données précédemment enregistrées déjà remplies.

![Vue principale de la page Modifier le formulaire](../imgs/forms/edit-form.png)

## Comment modifier une soumission

1.  Accédez à la liste des soumissions de votre formulaire.
2.  Repérez la soumission précise que vous souhaitez modifier.
3.  Cliquez sur le bouton **Modifier** (généralement représenté par une icône de crayon) correspondant à cette soumission. Le formulaire s'ouvre en mode édition.
4.  Apportez les modifications souhaitées à n'importe quel champ du formulaire.
5.  Choisissez une action en bas du formulaire :
    *   **Enregistrer le brouillon** : enregistre vos modifications actuelles sans soumettre le formulaire. Vous pouvez y revenir et le modifier à nouveau plus tard.
    *   **Soumettre** : enregistre toutes les modifications et soumet les données du formulaire mises à jour.

!!! tip "Suivi des modifications"
    Dino enregistre automatiquement les modifications que vous apportez entre la soumission d'origine et la version modifiée. Cela crée un historique indiquant qui a modifié quoi et quand.
