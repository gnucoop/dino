# Utilisateurs

La zone **Utilisateurs** est le centre névralgique pour gérer qui peut accéder à Dino et ce qu'il peut y faire. Depuis ici, vous pouvez accéder à deux sections d'administration clés : **Utilisateurs** (pour les comptes individuels) et **Groupes** (pour les ensembles de permissions).

![Vue principale de la page Utilisateurs](../imgs/administration/users.png)

Lorsque vous ouvrez la page Utilisateurs, vous voyez un menu avec les options suivantes :

*   **Utilisateurs** : ouvre la page [Gérer les utilisateurs](users-list.md) pour créer, modifier et gérer les comptes utilisateurs individuels.

    En cliquant sur cette option, vous accédez à la liste des utilisateurs, où vous pouvez voir tous les comptes, ajouter de nouveaux utilisateurs, modifier les détails et désactiver des comptes.

    ![Vue principale de la page Liste des utilisateurs](../imgs/administration/users-list.png)

*   **Groupes** : ouvre la page [Groupes](groups-list.md) pour créer et gérer des groupes de permissions qui contrôlent l'accès aux formulaires, rapports et données.

Cliquez simplement sur l'un ou l'autre élément du menu pour accéder à la section correspondante.

!!! warning "Accès administrateur requis"
    La zone Utilisateurs n'est visible que pour les utilisateurs ayant le rôle Administrateur. Si vous ne voyez pas cette page, contactez votre administrateur système.
