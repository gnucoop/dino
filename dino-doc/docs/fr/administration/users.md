# Utilisateurs

La zone **Utilisateurs** est le point central pour gérer qui peut accéder à Dino et ce qu'ils peuvent faire. Depuis cette page, vous pouvez accéder à deux sections d'administration clés : **Utilisateurs** (pour les comptes individuels) et **Groupes** (pour les ensembles d'autorisations).

![Main view of the Users page](../imgs/administration/users.png)

Lorsque vous ouvrez la page Utilisateurs, vous verrez un menu avec les options suivantes :

*   **Utilisateurs** : ouvre la page [Gérer les utilisateurs](users-list.md) pour créer, modifier et gérer des comptes utilisateurs individuels.

    En cliquant sur cette option, vous accédez à la liste des utilisateurs, où vous pouvez afficher tous les comptes, ajouter de nouveaux utilisateurs, modifier les détails et désactiver des comptes.

    ![Main view of the Users List page](../imgs/administration/users-list.png)

*   **Groupes** : ouvre la page [Groupes](groups-list.md) pour créer et gérer des groupes d'autorisations qui contrôlent l'accès aux formulaires, aux rapports et aux données.

Il suffit de cliquer sur l'un des éléments du menu pour accéder à la section correspondante.

!!! warning "Accès administrateur requis"
    La zone Utilisateurs n'est visible que par les utilisateurs disposant du rôle Administrateur. Si vous ne voyez pas cette page, contactez votre administrateur système.
