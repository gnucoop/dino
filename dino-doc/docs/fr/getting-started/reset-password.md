# Réinitialisation de votre mot de passe

La page Réinitialisation du mot de passe vous permet de choisir un nouveau mot de passe après avoir demandé un lien de réinitialisation. Vous y arrivez en cliquant sur le lien envoyé à votre adresse e-mail — le même lien que vous avez demandé via l'option **« Mot de passe oublié ? »** de la [page de connexion](login.md).

![Main view of the Reset Password page](../imgs/getting-started/reset-password.png)

!!! note
    Si vous n'avez pas encore demandé de lien de réinitialisation, allez d'abord sur la [page de connexion](login.md) et cliquez sur **« Mot de passe oublié ? »**.

---

## Définition d'un nouveau mot de passe

1.  Ouvrez le lien de réinitialisation du mot de passe depuis votre e-mail. Vous serez alors directement conduit à la page Réinitialisation du mot de passe.
2.  Saisissez votre **nouveau mot de passe** dans le premier champ. Votre mot de passe doit contenir au moins 9 caractères.
3.  Saisissez à nouveau le même mot de passe dans le champ **Confirmer le nouveau mot de passe** pour vérifier qu'il correspond.
4.  Cliquez sur le **bouton flèche** pour confirmer votre nouveau mot de passe.

Si le mot de passe est accepté, un message de confirmation apparaîtra en haut de l'écran et vous serez automatiquement redirigé(e) vers la page de connexion après quelques secondes. Vous pourrez ensuite vous connecter avec votre nouveau mot de passe.

---

## Dépannage

### « Votre ticket de réinitialisation du mot de passe est invalide ou a expiré. Veuillez réessayer. »

!!! warning
    Le lien que vous avez utilisé n'est plus valide. Les liens de réinitialisation expirent après un court délai pour des raisons de sécurité. Revenez à la [page de connexion](login.md), cliquez à nouveau sur **« Mot de passe oublié ? »** et demandez un nouveau lien.

### « Mot de passe incorrect »

!!! warning
    Le mot de passe n'a pas pu être enregistré. Assurez-vous que les deux champs contiennent exactement le même mot de passe et qu'il comporte au moins 9 caractères, puis réessayez. Si le problème persiste, demandez un nouveau lien de réinitialisation depuis la page de connexion.

### La page ne redirige pas après une réinitialisation réussie

!!! tip
    Si le message de confirmation apparaît mais que la page ne redirige pas d'elle-même vers la page de connexion, naviguez-y manuellement. Votre mot de passe a déjà été modifié avec succès.
