# Domaines thématiques

La page Domaines thématiques vous permet de créer et de gérer une liste hiérarchique de catégories pour vos données. Cela aide à organiser et filtrer les informations sur la plateforme.

![Main view of the Areas page](../imgs/metrics/areas.png)

Lorsque vous ouvrez la page, vous voyez une liste des domaines existants. Les principales colonnes affichées sont **Nom du domaine** et **Domaine parent**. Vous pouvez cliquer sur une ligne pour la sélectionner ou l'étendre pour voir plus de détails.

## Gestion des domaines

### Consulter un domaine
1.  Dans la liste, repérez le domaine que vous souhaitez consulter.
2.  Cliquez sur l'icône **œil** (visibilité) dans le menu d'actions de la ligne.
3.  Une boîte de dialogue s'ouvre affichant tous les détails de ce domaine.

### Créer un nouveau domaine
1.  Cliquez sur le bouton d'action flottant **+** (plus) dans le coin inférieur droit de l'écran.
2.  Un formulaire apparaît. Saisissez les informations requises, comme le **Nom du domaine**.
3.  Si ce domaine doit être une sous-catégorie, sélectionnez un domaine existant comme **Domaine parent**.
4.  Cliquez sur **Enregistrer** pour créer le nouveau domaine.

### Modifier un domaine
1.  Dans la liste, trouvez le domaine que vous souhaitez modifier.
2.  Cliquez sur l'icône **crayon** (modifier) dans le menu d'actions de cette ligne.
3.  Modifiez les informations dans le formulaire qui apparaît.
4.  Cliquez sur **Enregistrer** pour appliquer vos modifications.

### Supprimer un domaine
1.  Dans la liste, trouvez le domaine que vous souhaitez supprimer.
2.  Cliquez sur l'icône **corbeille** (supprimer) dans le menu d'actions de cette ligne.
3.  Une boîte de dialogue de confirmation apparaît. Confirmez la suppression.

!!! warning "Suppression de domaines"
    La suppression d'un domaine peut affecter la façon dont les données sont catégorisées. Assurez-vous qu'aucune soumission de données active ou d'autres métriques ne dépendent de ce domaine avant de le supprimer.

## Tri et organisation

Vous pouvez trier la liste alphabétiquement par la colonne **Nom du domaine**. Cliquez sur l'en-tête de la colonne pour basculer entre l'ordre croissant et décroissant.

!!! tip "Structure hiérarchique"
    Utilisez le champ **Domaine parent** pour créer une structure imbriquée, en forme d'arbre, pour vos catégories. Cela est utile pour créer des thèmes généraux avec des sous-thèmes spécifiques.
