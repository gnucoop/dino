# Métriques

Les métriques sont les catégories de données de référence utilisées dans Dino pour classer, organiser et filtrer vos données collectées. Lorsque vous remplissez un formulaire ou générez un rapport, vous sélectionnez des valeurs dans ces catégories — par exemple, en choisissant un projet, un lieu ou une organisation.

La zone Métriques est l'endroit où vous gérez les listes de valeurs disponibles pour chaque catégorie. Elle sert de hub central pour toutes vos données de référence.

![Main view of the Metrics page](../imgs/metrics/index.png)

---

## Types de métriques

La page principale affiche les types de métriques actifs dans votre installation Dino. Chaque type est présenté sous forme de carte avec une icône et un libellé. Cliquez sur une carte pour ouvrir sa page de gestion.

Selon la configuration de votre système, certains ou tous les types de métriques suivants peuvent être disponibles :

| Type de métrique | Description |
|---|---|
| **Domaines thématiques** | Domaines de travail ou regroupements thématiques pour vos activités. |
| **Cas** | Cas individuels, personnes ou bénéficiaires suivis à travers les soumissions de formulaires. |
| **Lieux** | Lieux géographiques où les données sont collectées ou les activités ont lieu. |
| **Projets** | Projets auxquels sont liés les soumissions de formulaires et les rapports. |
| **Organisations** | Organisations impliquées dans ou responsables des activités. |

!!! tip "Accès aux métriques"
    Vous pouvez naviguer vers la zone Métriques en cliquant sur **Métriques** dans le menu principal de l'application.

---

## Ce que vous pouvez faire

Depuis la page principale des métriques, vous pouvez :

1.  **Consulter tous les types de métriques actifs** disponibles pour vos données.
2.  **Naviguer vers un type de métrique spécifique** en cliquant sur sa carte. Cela vous amène à une page dédiée où vous pouvez gérer la liste des valeurs pour ce type (par exemple, ajouter un nouveau lieu ou modifier un nom de projet).
3.  **Utiliser le fil d'Ariane** en haut de la page pour suivre votre chemin de navigation dans la section Métriques.

Pour des instructions détaillées sur l'ajout, la modification ou la suppression de valeurs dans un type de métrique spécifique, consultez la documentation de chaque type de métrique : [Domaines](areas.md).

---

## Naviguer dans la zone Métriques

1.  Sur la page principale des métriques, consultez les cartes pour chaque type de métrique disponible.
2.  Cliquez sur la carte du type de métrique que vous souhaitez gérer (par exemple, **Lieux**).
3.  Vous serez redirigé vers une page dédiée à ce type de métrique, où vous pourrez consulter, ajouter, modifier ou supprimer des valeurs spécifiques.
4.  Utilisez le fil d'Ariane en haut de la page pour revenir facilement à la page principale des métriques ou à d'autres sections.

!!! warning "Configuration système"
    Les types de métriques disponibles sont configurés par votre administrateur système. Si vous ne voyez pas un type de métrique spécifique dont vous avez besoin, contactez votre administrateur.
