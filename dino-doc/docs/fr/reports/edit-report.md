# Modifier le rapport

La page Modifier le rapport vous permet de modifier un rapport existant. Vous pouvez mettre à jour ses métriques, ses détails et d'autres informations une fois qu'il a été créé.

![Vue principale de la page Modifier le rapport](../imgs/reports/edit-report.png)

## Accéder à la page de modification

Vous pouvez accéder à la page Modifier le rapport de deux manières :

* Depuis la liste principale [Rapports](index.md), cliquez sur le titre d'un rapport ou sur l'action **Modifier** (souvent représentée par une icône de crayon).
* Depuis la vue détaillée d'un rapport (après avoir cliqué sur **Voir le rapport**), recherchez un bouton ou un lien **Modifier**.

## Modifier les informations du rapport

Une fois sur la page Modifier le rapport, vous verrez un formulaire semblable à celui utilisé pour créer un rapport. Le formulaire est prérempli avec les données actuelles du rapport.

### Étapes pour modifier un rapport

1. **Vérifiez les données préremplies** dans les champs du formulaire.
2. **Apportez vos modifications** à l'un des champs disponibles :
   - **Métriques principales :** mettez à jour les principales valeurs numériques du rapport.
   - **Métriques secondaires :** modifiez des points de données supplémentaires (si votre schéma de formulaire le prévoit).
   - **Détails :** modifiez le texte descriptif, les dates ou toute autre information complémentaire.
3. **Enregistrez vos modifications** en cliquant sur le bouton **Enregistrer** ou **Mettre à jour** en bas du formulaire.

!!! tip "Champs facultatifs"
    Selon la configuration de votre organisation, certains champs de métriques peuvent être facultatifs. Ils sont généralement signalés comme tels. Vous pouvez laisser les champs facultatifs vides si aucune donnée n'est disponible.

## Afficher le rapport mis en forme

Après avoir enregistré vos modifications, vous pouvez consulter le rapport mis en forme. Cliquez sur le bouton ou le lien **Voir le rapport** pour afficher une version propre et mise en forme des données du rapport.

![Vue du rapport mis en forme après avoir cliqué sur Voir le rapport](../imgs/reports/edit-report-view.png)

## Comprendre le schéma de formulaire

La structure et les champs disponibles sur la page Modifier le rapport sont déterminés par le **schéma de formulaire** défini par votre administrateur. Cela garantit une collecte de données cohérente.

![Vue principale de la page Modifier le schéma de rapport](../imgs/reports/edit-report-schema.png)

Si vous devez modifier une information qui n'apparaît pas sous forme de champ, contactez votre administrateur – le schéma de formulaire devra peut-être être mis à jour. Pour en savoir plus sur la structure sous-jacente, consultez la documentation [Modifier le schéma de rapport](edit-report-schema.md).

!!! warning "Intégrité des données"
    Soyez prudent lorsque vous modifiez des données de rapport anciennes, car les changements peuvent affecter l'analyse des tendances et les enregistrements historiques. Assurez-vous que vos mises à jour sont exactes.
