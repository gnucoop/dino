# Rapports

La zone Rapports est votre point d'accès à tous les schémas de rapport disponibles. Un schéma de rapport définit la structure et le contenu d'un rapport pouvant être généré à partir des données que vous avez collectées. C'est ici que vous pouvez parcourir les schémas et accéder aux rapports déjà créés.

![Main view of the Reports page](../imgs/reports/index.png)

Les rapports ne peuvent être créés qu'à l'aide d'un format basé sur Excel appelé [XLSReport](xlsreport.md). Pour créer un nouveau rapport, vous devez d'abord créer un fichier XLSReport, puis l'importer dans Dino en suivant la procédure décrite ci-dessous.

---

## Parcourir les schémas de rapport

Lorsque vous ouvrez la page Rapports, vous voyez la liste de tous les schémas de rapport auxquels vous avez accès. La liste est triée par ordre alphabétique selon le libellé du schéma.

Pour trouver un schéma précis :

1. Utilisez la barre de recherche en haut de la page.
2. Saisissez une partie quelconque du nom ou du libellé du schéma.
3. La liste se filtre en temps réel pour n'afficher que les schémas correspondants.

Pour consulter les rapports d'un schéma précis, cliquez sur sa carte dans la liste.

!!! tip "Pour bien démarrer"
    Si vous voyez le message « Il n'y a pas de rapports », cela signifie qu'aucun schéma de rapport n'a encore été créé ou partagé avec vous. Contactez votre administrateur Dino pour commencer.

---

## Créer un nouveau schéma de rapport

Vous pouvez lancer la création d'un nouveau schéma de rapport directement depuis la page principale Rapports. Cliquez sur le bouton **+** (plus) situé dans le coin inférieur droit de l'écran.

Pour connaître les étapes détaillées, consultez le guide sur [Modifier le rapport](edit-report.md).

---

## Ce que vous pouvez faire

Depuis la page principale Rapports, vous pouvez accéder aux actions clés suivantes :

* **[Modifier le rapport](edit-report.md)** — Générez un nouveau document de rapport en sélectionnant un schéma, en choisissant vos métriques et en définissant une plage de dates.
* **[Modifier le schéma de rapport](edit-report-schema.md)** — Créez de nouveaux schémas de rapport ou modifiez ceux qui existent déjà pour définir quelles données apparaissent dans les rapports. Cela nécessite généralement des autorisations d'administrateur.
