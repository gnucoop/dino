# Rapports

La zone Rapports est votre centre pour accéder à tous les schémas de rapport disponibles. Un schéma de rapport définit la structure et le contenu d'un rapport pouvant être généré à partir de vos données collectées. À partir de là, vous pouvez parcourir les schémas et accéder aux rapports déjà créés.

![Main view of the Reports page](../imgs/reports/index.png)

---

## Parcourir les schémas de rapport

Lorsque vous ouvrez la page Rapports, vous voyez une liste de tous les schémas de rapport auxquels vous avez l'autorisation d'accéder. La liste est triée alphabétiquement par le libellé du schéma.

Pour trouver un schéma spécifique :

1. Utilisez la barre de recherche en haut de la page.
2. Saisissez une partie du nom ou du libellé du schéma.
3. La liste se filtre en temps réel pour n'afficher que les schémas correspondants.

Pour afficher les rapports d'un schéma spécifique, cliquez sur sa carte dans la liste.

!!! tip "Pour commencer"
    Si vous voyez le message « Aucun rapport », cela signifie qu'aucun schéma de rapport n'a encore été créé ni partagé avec vous. Contactez votre administrateur Dino pour commencer.

---

## Créer un nouveau rapport

Vous pouvez lancer le processus de génération d'un nouveau rapport directement depuis la page principale Rapports.

1. Cliquez sur le bouton **+** (plus) situé dans le coin inférieur droit de l'écran.
2. Un menu ou une boîte de dialogue s'ouvre pour vous permettre de sélectionner le schéma de rapport à utiliser.
3. Après avoir sélectionné un schéma, vous êtes dirigé vers le formulaire de création de rapport pour choisir vos indicateurs, définir une plage de dates et générer le rapport.

!!! warning "Crédits requis"
    Certains schémas de rapport peuvent nécessiter des crédits Dino-AI pour être générés. Si vous n'avez pas assez de crédits, il vous sera demandé d'en ajouter à votre compte avant de continuer.

Pour les étapes détaillées, consultez le guide [Modifier le rapport](edit-report.md).

---

## Ce que vous pouvez faire

À partir de la page principale Rapports, vous pouvez accéder aux actions clés suivantes :

* **[Modifier le rapport](edit-report.md)** — Générer un nouveau document de rapport en sélectionnant un schéma, vos indicateurs et une plage de dates.
* **[Modifier le schéma de rapport](edit-report-schema.md)** — Créer de nouveaux schémas de rapport ou modifier ceux existants pour définir quelles données apparaissent dans les rapports. Cela nécessite généralement des autorisations d'administrateur.
