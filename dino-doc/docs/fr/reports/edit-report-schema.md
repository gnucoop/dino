# Modifier le schéma de rapport

La page **Modifier le schéma de rapport** vous permet de créer un nouveau schéma de rapport ou d’en modifier un existant. Un schéma de rapport définit la structure, la mise en page et les sources de données d’un rapport dans Dino.

![Main view of the Edit Report Schema page](../imgs/reports/edit-report-schema.png)

Sur cette page, vous configurez le nom, la description et les champs de données spécifiques du rapport qui apparaîtront dans celui-ci à partir de vos soumissions de formulaire.

## Création d’un nouveau schéma de rapport

Pour créer un nouveau schéma de rapport :

1. Accédez à la section **Rapports** dans le menu principal.
2. Cliquez sur **Créer un schéma de rapport**.
3. Vous êtes redirigé vers la page Modifier le schéma de rapport.
4. Saisissez un **Nom** descriptif pour votre rapport.
5. (Facultatif) Fournissez une **Description** pour expliquer l’objectif du rapport.
6. Configurez les données et la mise en page du rapport à l’aide des options disponibles.
7. Cliquez sur **Enregistrer** pour créer le schéma.

## Modification d’un schéma de rapport existant

Pour modifier un schéma de rapport que vous avez déjà créé :

1. Accédez à la section **Rapports**.
2. Recherchez le schéma de rapport que vous souhaitez modifier dans la liste et cliquez dessus.
3. Cliquez sur le bouton **Modifier** (souvent représenté par une icône de crayon).
4. Vous êtes redirigé vers la page Modifier le schéma de rapport avec la configuration actuelle chargée.
5. Apportez les modifications souhaitées au nom, à la description ou à la configuration des données.
6. Cliquez sur **Enregistrer** pour mettre à jour le schéma.

!!! tip "Enregistrer votre travail"
    Pensez toujours à cliquer sur **Enregistrer** après avoir effectué des modifications. Vos modifications ne sont appliquées qu’après l’enregistrement du schéma.

## Configuration des données du rapport

Le cœur du schéma de rapport consiste à définir quelles données de vos soumissions de formulaire apparaîtront dans le rapport. Vous pouvez généralement :

* **Sélectionner la source de données :** choisissez le schéma de formulaire contenant les données que vous souhaitez utiliser pour le rapport.
* **Sélectionner les champs de données :** choisissez des champs spécifiques parmi vos schémas de formulaire connectés pour les inclure comme colonnes dans le rapport.
* **Définir les noms affichés :** personnalisez l’en-tête de colonne affiché dans le rapport pour chaque champ sélectionné.
* **Définir des filtres :** définissez des conditions pour n’inclure que les soumissions spécifiques qui répondent à vos critères (par exemple, les soumissions d’une certaine période).

!!! warning "Source de données"
    Un schéma de rapport doit être connecté à au moins un schéma de formulaire pour pouvoir afficher des données. Assurez-vous que le formulaire concerné existe avant de créer votre rapport.

## Prochaines étapes

Après avoir enregistré votre schéma de rapport, vous pouvez :

* Accéder à la page [Rapports](index.md) pour consulter et exécuter votre nouveau rapport.
* Revenir sur cette page pour effectuer d’autres ajustements si nécessaire.
