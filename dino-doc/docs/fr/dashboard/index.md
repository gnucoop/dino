# Tableau de bord

Le tableau de bord est le premier écran que vous voyez après vous être connecté à Dino. Il sert de point central pour naviguer dans l'application. Selon la configuration de votre système, votre tableau de bord apparaît sous l'un des deux formats suivants : un **tableau de bord de type menu** ou un **tableau de bord de type rapport**.

![Main view of the Dashboard page](../imgs/dashboard/index.png)

---

## Tableau de bord de type menu

Dans ce format, le tableau de bord présente une grille de cartes de navigation. Chaque carte donne un accès rapide à un domaine principal de l'application pour lequel vous disposez des autorisations nécessaires.

Vous verrez généralement les cartes suivantes :

*   **Formulaires** : Accédez à la zone [Formulaires](../forms/index.md) pour créer des schémas de formulaires, collecter des données et examiner les soumissions.
*   **Rapports** : Accédez à la zone [Rapports](../reports/index.md) pour créer, afficher et gérer des rapports basés sur vos données collectées.
*   **Métriques** : Accédez à la zone [Métriques](../metrics/index.md) pour gérer les données de référence telles que les projets, les emplacements et les organisations.
    !!! warning "Visibilité"
        La carte Métriques est masquée si votre compte utilisateur ne dispose que d'autorisations d'invité.
*   **Utilisateurs** : Accédez à la zone [Gérer les utilisateurs](../administration/users-list.md) pour gérer les comptes et les groupes d'utilisateurs.
    !!! tip "Accès administrateur"
        La carte Utilisateurs n'est visible que pour les utilisateurs disposant de privilèges d'administrateur.

Pour naviguer, cliquez simplement sur la carte de la zone à laquelle vous souhaitez accéder.

## Tableau de bord de type rapport

Dans ce format, votre tableau de bord est personnalisé pour afficher un rapport unique que vous avez marqué comme favori. Cela vous permet de consulter les visualisations de données clés immédiatement après la connexion.

Si vous n'avez pas encore sélectionné de rapport favori, un message de bienvenue vous invite à en ajouter un.

### Définir un rapport favori

1.  Accédez à la zone [Rapports](../reports/index.md).
2.  Ouvrez le rapport que vous souhaitez voir sur votre tableau de bord.
3.  Dans la liste des rapports ou dans la vue du rapport, recherchez et cliquez sur l'action **Ajouter aux favoris** (généralement représentée par une icône en forme de cœur).
4.  Actualisez ou revenez à votre tableau de bord. Le rapport sélectionné s'affichera désormais.

### Changer ou supprimer un favori

Pour changer de rapport favori, ajoutez simplement un autre rapport à vos favoris. Le nouveau rapport remplacera l'ancien sur votre tableau de bord. Pour vider le tableau de bord, vous pouvez supprimer le paramètre de rapport favori du stockage local de votre navigateur, ou contacter votre administrateur système.
