## التنقل الجانبي

تتيح لك القائمة الجانبية التنقل بين الأقسام الرئيسية للتطبيق.

**الأقسام القياسية** (مرئية لجميع المستخدمين الموثّقين):

| القسم | الوصف |
|---|---|
| لوحة البيانات | الشاشة الرئيسية. |
| النماذج | نماذج جمع البيانات والإرسالات. |
| التقارير | التقارير المنشأة. |
| التجميع | عرض موحد للإرسالات عبر نماذج متعددة. |
| المقاييس | البيانات المرجعية (المشاريع، المواقع، المؤسسات، إلخ). *(مخفية للمستخدمين الضيوف فقط.)* |
| GPT | المساعد الذكي (DinoGPT). |

**الأقسام الإدارية** (مرئية للمسؤولين فقط، تظهر أسفل فاصل):

| القسم | الوصف |
|---|---|
| المستخدمون | حسابات المستخدمين ومجموعات الصلاحيات. |
| اللغات | إدارة ترجمة الواجهة. |

على الشاشات الكبيرة، تكون القائمة مرئية دائمًا على اليسار
