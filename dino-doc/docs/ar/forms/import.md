# استيراد البيانات

تتيح لك صفحة **استيراد البيانات** رفع البيانات بشكل جماعي إلى form schema من ملف بامتداد `.xls` أو `.xlsx` أو `.csv`. يرشدك معالج مكوّن من خطوتين خلال رفع الملف وربط أعمدته بحقول النموذج.

![العرض الرئيسي لصفحة استيراد البيانات](../imgs/forms/import.png)

## الوصول إلى صفحة الاستيراد

1. انتقل إلى قائمة **Forms** واختر form schema.
2. من عرض بيانات النموذج، انقر على **Import** (زر شريط الأدوات).

## الخطوة 1 — رفع الملف

تعرض الخطوة الأولى منطقة سحب وإفلات أو أداة اختيار ملف.

- **الصيغ المقبولة:** `.xls`، `.xlsx`، `.csv`
- **الحد الأقصى لحجم الملف:** 20 ميغابايت

للرفع:

1. اسحب ملفًا إلى المنطقة المتقطعة **أو** انقر على **Choose a file** للتصفح.
2. بعد الاختيار، يظهر اسم الملف في شريحة صغيرة إلى جانب عدد الأعمدة المكتشفة.
3. (اختياري) أبقِ خيار **Reuse existing metrics with the same name** محدَّدًا (الوضع الافتراضي) بحيث يُربط أي metric في الملف يتطابق اسمه مع metric موجود بالفعل في النظام بذلك الـ metric الموجود بدلًا من إنشاء نسخة مكررة. ألغِ التحديد لإنشاء metrics جديدة دائمًا.
4. انقر على **Next** (أو على تسمية الخطوة "2 · Map fields") للمتابعة.

### تنسيق ملف الاستيراد
راجع الوصف في القسم [أدناه](#تنسيق-الملف)

!!! tip "صيغ الملفات السهلة"
    يقبل Dino الملف نفسه الذي يتم الحصول عليه أثناء [التصدير](index.md#التصدير). لذا، فإن أسهل طريقة للحصول على ملف منسّق بشكل صحيح للاستيراد هي أولًا تصدير بعض بيانات form من الـ schema نفسه ثم حذف الصفوف التي تحتوي على البيانات المصدَّرة، مع الإبقاء على رؤوس الأعمدة فقط. في جميع الأحوال، تأكد من أن رؤوس أعمدتك واضحة – إذ ستُستخدم كاقتراحات أثناء الربط.

!!! note "الـ Metrics محدَّدة بالمعرّف"
    إذا كان عمود metric في ملفك يوفّر **ID** الخاص بالـ metric (UUID)، فإن ذلك الصف يُربط بالـ metric الموجود بذلك المعرّف ولا يُنشأ metric جديد. للمعرّف الأولوية على اسم الـ metric، لذا يحدث ذلك بغض النظر عن خيار **Reuse existing metrics with the same name** (الذي ينطبق فقط على المطابقة بالاسم).

## الخطوة 2 — ربط الحقول

بعد الرفع، ترى جدولًا يسرد جميع الأعمدة من ملفك. يحتوي كل صف على ثلاثة أعمدة:

- **File column** – الرأس الأصلي من ملفك.
- **Form field** – قائمة منسدلة تختار منها حقل النموذج المقابل.
- **Status** – يُظهر ما إذا كان العمود مربوطًا أو مُتجاهَلًا أو يحتوي على خطأ.

### إجراءات الربط

- **اختيار حقل النموذج** – افتح القائمة المنسدلة لعمود واختر الحقل الصحيح. يمكنك البحث داخل القائمة المنسدلة.
- **تجاهل عمود** – اختر خيار **— Ignore this column —** في القائمة المنسدلة، أو انقر على زر **Ignore** في عمود الحالة. تظهر الأعمدة المُتجاهَلة باهتة.
- **استعادة عمود مُتجاهَل** – انقر على زر **Restore** في عمود الحالة.

### المطابقة التلقائية

انقر على **Auto‑match** ليتولى Dino إقران الأعمدة بحقول النموذج تلقائيًا بناءً على تشابه الأسماء. تُعدّ هذه نقطة بداية جيدة – راجع عمليات الربط وعدّلها حسب الحاجة.

!!! tip "تعمل المطابقة التلقائية بأفضل شكل مع الرؤوس التي تطابق تسميات الحقول تمامًا أو تحتوي على كلمات مفتاحية مشابهة."

### التكرار

إذا كان حقل النموذج المحدد حقلًا متكررًا (مثل أرقام هاتف متعددة)، يظهر حقل إدخال **Repetition** أسفل القائمة المنسدلة. أدخل فهرس التكرار (0، 1، 2، …) لإسناد عمود الملف هذا إلى أحد تكرارات المجموعة المتكررة.

### ملخص شريط الأدوات

في أعلى منطقة الربط، يمكنك رؤية ثلاث شرائح صغيرة:

- **Total columns** – عدد أعمدة الملف.
- **Mapped** – الأعمدة التي أُسندت إلى حقل نموذج.
- **Ignored** – الأعمدة التي اخترت تجاهلها.

استخدم حقل إدخال **Search columns** لتصفية الجدول حسب اسم عمود الملف.

## تطبيق الاستيراد

عندما تُربط جميع الأعمدة المطلوبة ولا توجد أخطاء، يصبح زر **Apply import** مُفعَّلًا. انقر عليه لبدء الاستيراد. أثناء المعالجة، يظهر مؤشر تحميل دوّار. يمكنك النقر على **Back** للعودة إلى الخطوة 1 أو إلغاء الاستيراد.

بعد استيراد ناجح، تعود إلى قائمة بيانات النموذج، حيث تظهر البيانات الجديدة.

!!! warning "ربط مكرر"
    إذا ربطت حقل النموذج نفسه بأكثر من عمود ملف، يظهر خطأ في التحقق ويبقى زر **Apply import** معطَّلًا حتى تصحيح ذلك.


## تنسيق الملف

نوضح الإجراء الخاص باستيراد بعض البيانات بشكل جماعي باستخدام ملف Excel مُنشأ من Google Sheet. ينطبق الإجراء نفسه على ملفات CSV أو عند العمل مباشرة مع Excel.

نفترض أنك تريد استيراد بيانات في form يُسمى Projects يحتوي على شريحتين، إحداهما شريحة متكررة:

![The Projects form, with two slides one of which is a repeating slide](../imgs/forms/import-repeating-slide.png)

أُنشئ form Projects باستخدام ملف XLSForm التالي. ورقة "survey" هي

| type | name | label |
| ----- | ----- | ----- |
| **begin group** | **start** | **Start** |
| select\_one countries | country | Country |
| select\_multiple countries | country\_other | Other Countries |
| text | title | Project Title |
| date | project\_date\_start | Start date |
| select\_one donors | selected\_donor | Donor |
| integer | budget | Budget |
| boolean | isleader | Leading applicant |
| **end group** |  |  |
| **begin repeat** | **indicators** | **Indicators** |
| text | indic | Indicator description |
| integer | value\_indic | Value reached |
| **end repeat** |  |  |

وورقة "choices" هي

| list\_name | name | label |
| ----- | ----- | ----- |
| donors | ue | UE |
| donors | govita | ITALIAN GOVERNMENT |
| donors | un | UN |
| donors | pub | ALTRI DONATORI PUBBLICI |
| donors | la | ENTI LOCALI |
| donors | priv | DONATORI PRIVATI |
| donors | other | Others |
|  |  |  |
| countries | AFG | Afghanistan |
| countries | ALB | Albania |
| countries | DZA | Algeria |
| countries | ASM | American Samoa |

اتبع هذه الخطوات:

1. أنشئ ملفًا فارغًا بورقة واحدة فقط (أسماء الملف والورقة لا تهم).
2. في الصف الأول تحتاج إلى وضع أسماء حقول النموذج والحقول الخاصة بـ DINO. في هذا المثال، يمكن أن تكون حقول النموذج:
   1. **country**
   2. **country\_other**
   3. **title**
   4. **project\_date\_start**
   5. **selected\_donor**
   6. **budget**
   7. **isleader**
   8. ***indic*** (\*)
   9. ***value\_indic*** (\*)

   انتبه إلى أن الحقول الواقعة ضمن شرائح متكررة تحتاج إلى معالجة مختلفة (ولهذا وضعنا نجمة). يُرجى الرجوع إلى القسم المحدد أدناه.

   يمكن أن تكون الحقول الخاصة بـ DINO:

   10. **created\_at**. تاريخ إنشاء الـ form. حدّده فقط إذا كنت تريد أن يكون لـ forms الخاصة بك تاريخ إنشاء مختلف عن تاريخ الاستيراد؛
   11. **user\_data\_ref\_id**. معرّف المستخدم الذي سيُربط بالـ form (الافتراضي هو معرّف المستخدم الذي يستورد الـ forms)؛
   12. **area\_id**. معرّف الـ metric AREA الذي سيُربط بالـ form؛
   13. \[area\_name\]
   14. **case\_id**. معرّف الـ metric CASE الذي سيُربط بالـ form؛
   15. \[case\_name\]
   16. **project\_id**. معرّف الـ metric PROJECT الذي سيُربط بالـ form؛
   17. \[project\_name\]
   18. \[project\_code\]
   19. **location\_id**. معرّف الـ metric LOCATION الذي سيُربط بالـ form؛
   20. \[location\_name\]
   21. **organization\_id**. معرّف الـ metric ORGANISATION الذي سيُربط بالـ form؛
   22. \[organization\_name\]

3. سيتوافق كل صف مع form جديد مختلف. لذا، إذا أنشأنا ملفًا برأس واحد \+، لنقل، 5 صفوف من البيانات، وإذا نجح الرفع، فسننشئ 5 forms جديدة في DINO.
4. ليس من الضروري أن يكون لديك عمود لكل حقل في النموذج؛ وليس من الضروري ملء جميع صفوف عمود معين، ولكن إذا كان أحد الحقول فارغًا لجميع الصفوف، فيمكن حذفه،
5. يجب تنسيق حقل التاريخ بصيغة YYYY-MM-DD كنص (انتبه).
6. يجب أن تحتوي حقول الاختيار الفردي على أحد الخيارات المقبولة كما هو محدَّد في "choices" (راجع منشئ النموذج أو ملف XLSForm).
7. يجب تنسيق حقول الاختيار المتعدد وفق النمط التالي: \[opt1, opt2\] (أي قائمة خيارات بين قوسين مربعين).

على سبيل المثال، يمكن أن يكون الملف الصالح كالتالي:

| country | country\_other | title | project\_date\_start | budget | isleader | area\_id |
| :---- | :---- | :---- | :---- | ----- | :---- | :---- |
| ALB | \[AFG,DZA\] | Human rights in education | 2022-01-28 | 120000 | true | 81387ff7-5c7d-44e7-9dc6-76b8d09265ac |
| ASM |  | A new approach to social justice | 2022-02-14 | 20000 |  | 81387ff7-5c7d-44e7-9dc6-76b8d09265ac |

في هذه الحالة نستورد 2 forms، ولكليهما نختار فقط الـ metric AREA. علاوة على ذلك، لاحظ أننا لا نوفّر جميع حقول النموذج لجميع الـ forms، لكن بالنسبة للحقول التي نوفّر لها قيمة، فإننا نتبع بدقة الإرشادات الموضحة أعلاه.

### التعامل مع الـ metrics أثناء الاستيراد

أثناء استيراد بعض بيانات form، وفيما يتعلق بالـ metrics، قد ترغب في:

- إنشاء metrics جديدة أثناء الاستيراد
- إعادة استخدام metrics منشأة بالفعل

القواعد التي يجب اتباعها لإدارة الـ metrics بشكل صحيح هي التالية:

| المقياس | الإنشاء من الواجهة | الإنشاء عبر الاستيراد | الإنشاء \+ التعيين عبر الاستيراد | الاستخدام عبر الاستيراد | الإنشاء \+ التعيين عبر الاستيراد (parent) | الاستخدام كـ parent |
| ----- | ----- | ----- | ----- | ----- | ----- | ----- |
| **Case** | name | name | name | id، أو name (مع خيار reuse)، أو كلاهما | name | id، أو name (مع خيار reuse)، أو كلاهما |
| **Organization** | name | name | name | id، أو name (مع خيار reuse)، أو كلاهما | name | id، أو name (مع خيار reuse)، أو كلاهما |
| **Location** | name | name | name | id، أو name (مع خيار reuse)، أو كلاهما | name | id، أو name (مع خيار reuse)، أو كلاهما |
| **Area** | name | name | name | id، أو name (مع خيار reuse)، أو كلاهما | name | id، أو name (مع خيار reuse)، أو كلاهما |
| **Project** | name, code | name, code | name, code | id | name, code | id |

## الشرائح المتكررة

إذا كان لديك حقل في شرائح متكررة، فيجب تسميته بشكل مختلف. يجب أن يُسمى كل حقل في الشريحة المتكررة \<field\_name\>\_\_X حيث X هو رقم التكرار، من 0 (الموافق لتكرار واحد) إلى N-1 حيث N هو العدد الإجمالي لتكرارات الشريحة في ذلك الـ form.
على سبيل المثال، لنفترض أن لديك تكرارًا واحدًا فقط من الشريحة المتكررة وتريد إضافة كلا الحقلين "Indicator description" و"Value reached". ستحتاج إلى إضافة هذين العمودين إلى ملف الاستيراد:

| indic\_\_0 | value\_indic\_\_0 |
|  :---- | ----- |
| Number of children | 100 |

فمثلًا يمكن أن يكون لدينا:

| country | budget | indic\_\_0 | value\_indic\_\_0 | indic\_\_1 | value\_indic\_\_1 | isleader |
| :---- | ----- | :---- | ----- | :---- | ----- | :---- |
| ALB | 120000 | Children | 100 |  |  | true |
| ASM | 20000 |  |  |  |  |  |
| AFG | 15000 | Parents | 45 | Schools | 34 | true |

## الأخطاء

تحقق من المعرّفات في ملفك قبل الاستيراد. إذا كان عمود يشير إلى كيان من خلال معرّفه (مقياس أو مستخدم) ولم يكن هناك كيان بهذا المعرّف في Dino، فلن يمكن مزامنة النماذج المستوردة مع الخادم.
