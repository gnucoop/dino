# تحرير report schema

تتيح لك صفحة **تحرير report schema** إنشاء report schema جديد أو تعديل واحد موجود. يحدد report schema البنية والتخطيط ومصادر البيانات للـ report في Dino.

![العرض الرئيسي لصفحة تحرير report schema](../imgs/reports/edit-report-schema.png)

في هذه الصفحة، تقوم بتهيئة اسم الـ report ووصفه وحقول البيانات المحددة التي ستظهر في الـ report من بيانات الـ form الخاصة بك.

## إنشاء report schema جديد

لإنشاء report schema جديد:

1. انتقل إلى قسم **Reports** في القائمة الرئيسية.
2. انقر على **Create Report Schema**.
3. يتم نقلك إلى صفحة تحرير report schema.
4. أدخل **Name** وصفيًا للـ report الخاص بك.
5. (اختياري) قدّم **Description** لشرح الغرض من الـ report.
6. استورد ملف XLSReport.
7. انقر على **Save** لإنشاء الـ schema.

## تحرير report schema موجود

لتعديل report schema قمت بإنشائه مسبقًا:

1. انتقل إلى قسم **Reports**.
2. ابحث عن report schema الذي ترغب في تحريره في القائمة وانقر عليه.
3. انقر على زر **Edit** (غالبًا ما يُمثَّل بأيقونة قلم رصاص).
4. يتم نقلك إلى صفحة تحرير report schema مع تحميل التهيئة الحالية.
5. أجرِ التغييرات المطلوبة على الاسم أو الوصف أو تهيئة البيانات.
6. انقر على **Save** لتحديث الـ schema.

!!! tip "حفظ عملك"
    تذكّر دائمًا النقر على **Save** بعد إجراء التغييرات. لا تُطبَّق تعديلاتك حتى تحفظ الـ schema.

## تهيئة بيانات الـ report

يكمن جوهر report schema في تحديد البيانات التي ستظهر في الـ report من بيانات الـ form الخاصة بك. يمكنك عادةً:

* **اختيار مصدر البيانات:** اختر form schema الذي يحتوي على البيانات التي تريد إعداد report عنها.
* **اختيار حقول البيانات:** اختر حقولًا محددة من form schemas المتصلة لتضمينها كأعمدة في الـ report.
* **تعيين أسماء العرض:** خصّص عنوان العمود المعروض في الـ report لكل حقل محدد.
* **تحديد الفلاتر:** حدّد شروطًا لتضمين بيانات محددة فقط تستوفي معاييرك (على سبيل المثال، البيانات الواردة ضمن نطاق زمني معين).

!!! warning "مصدر البيانات"
    يجب ربط report schema بـ form schema واحد على الأقل ليكون لديه بيانات لعرضها. تأكد من وجود الـ form ذي الصلة قبل إنشاء الـ report الخاص بك.

## الخطوات التالية

بعد حفظ report schema الخاص بك، يمكنك:

* الانتقال إلى صفحة [Reports](index.md) لعرض وتشغيل الـ report الجديد الخاص بك.
* العودة إلى هذه الصفحة لإجراء مزيد من التعديلات حسب الحاجة.
