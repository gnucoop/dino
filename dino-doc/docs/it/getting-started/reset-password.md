# Reimpostazione della password

La pagina Reimposta password ti permette di scegliere una nuova password dopo aver richiesto un link di reimpostazione. Arrivi qui facendo clic sul link inviato al tuo indirizzo email: lo stesso link che hai richiesto tramite l'opzione **"Password dimenticata?"** nella [pagina di accesso](login.md).

![Main view of the Reset Password page](../imgs/getting-started/reset-password.png)

!!! note
    Se non hai ancora richiesto un link di reimpostazione, vai prima alla [pagina di accesso](login.md) e fai clic su **"Password dimenticata?"**.

---

## Impostare una nuova password

1.  Apri il link di reimpostazione della password dalla tua email. Verrai portato direttamente alla pagina Reimposta password.
2.  Inserisci la tua **nuova password** nel primo campo. La password deve essere lunga almeno 9 caratteri.
3.  Reinserisci la stessa password nel campo **Conferma nuova password** per assicurarti che corrisponda.
4.  Fai clic sul **pulsante freccia** per confermare la tua nuova password.

Se la password viene accettata, apparirà un messaggio di conferma nella parte superiore dello schermo e verrai reindirizzato automaticamente alla pagina di accesso dopo qualche secondo. Potrai quindi accedere con la tua nuova password.

---

## Risoluzione dei problemi

### "Il ticket per la reimpostazione della password non è valido o è scaduto. Riprova."

!!! warning
    Il link che hai utilizzato non è più valido. Per motivi di sicurezza, i link di reimpostazione scadono dopo poco tempo. Torna alla [pagina di accesso](login.md), fai di nuovo clic su **"Password dimenticata?"** e richiedi un nuovo link.

### "Password non corretta"

!!! warning
    La password non è stata salvata. Assicurati che entrambi i campi contengano esattamente la stessa password e che sia lunga almeno 9 caratteri, quindi riprova. Se il problema persiste, richiedi un nuovo link di reimpostazione dalla pagina di accesso.

### La pagina non reindirizza dopo una reimpostazione riuscita

!!! tip
    Se il messaggio di conferma appare ma la pagina non viene reindirizzata automaticamente alla pagina di accesso, spostati lì manualmente. La tua password è già stata modificata correttamente.
