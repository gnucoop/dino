# Reimpostare la Password

La pagina di reimpostazione della password ti consente di scegliere una nuova password dopo aver richiesto un link di reimpostazione. Arrivi qui facendo clic sul link inviato al tuo indirizzo email — lo stesso link richiesto tramite l'opzione **"Password dimenticata?"** nella [pagina di accesso](login.md).

![Vista principale della pagina di reimpostazione password](../imgs/getting-started/reset-password.png)

!!! note
    Se non hai ancora richiesto un link di reimpostazione, vai prima alla [pagina di accesso](login.md) e clicca su **"Password dimenticata?"**.

---

## Impostare una Nuova Password

1.  Apri il link di reimpostazione della password ricevuto via email. Verrai portato direttamente alla pagina di reimpostazione.
2.  Inserisci la **nuova password** nel primo campo. La password deve essere lunga almeno 9 caratteri.
3.  Reinserisci la stessa password nel campo **Conferma nuova password** per assicurarti che corrisponda.
4.  Clicca sul **pulsante a freccia** per confermare la nuova password.

Se la password viene accettata, apparirà un messaggio di conferma nella parte superiore dello schermo e verrai automaticamente reindirizzato alla pagina di accesso dopo pochi secondi. Potrai quindi accedere con la tua nuova password.

---

## Risoluzione dei Problemi

### "Il ticket di reimpostazione password non è valido o è scaduto. Riprova."

!!! warning
    Il link utilizzato non è più valido. I link di reimpostazione scadono dopo poco tempo per motivi di sicurezza. Torna alla [pagina di accesso](login.md), clicca di nuovo su **"Password dimenticata?"** e richiedi un nuovo link.

### "Password non corretta"

!!! warning
    La password non è stata salvata. Assicurati che entrambi i campi contengano esattamente la stessa password e che sia lunga almeno 9 caratteri, quindi riprova. Se il problema persiste, richiedi un nuovo link di reimpostazione dalla pagina di accesso.

### La pagina non reindirizza dopo un reset riuscito

!!! tip
    Se il messaggio di conferma appare ma la pagina non reindirizza automaticamente alla pagina di accesso, naviga manualmente verso di essa. La tua password è già stata cambiata con successo.
