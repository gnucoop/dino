# Dashboard

La Dashboard è la prima schermata che vedi dopo aver effettuato l'accesso a Dino. Funge da punto centrale per la navigazione nell'applicazione. A seconda della configurazione del tuo sistema, la Dashboard apparirà in uno dei due layout: una **Dashboard a Menu** o una **Dashboard Report**.

![Main view of the Dashboard page](../imgs/dashboard/index.png)

---

## Dashboard a Menu

In questo layout, la Dashboard presenta una griglia di schede di navigazione. Ogni scheda fornisce un accesso rapido a un'area principale dell'applicazione che hai il permesso di utilizzare.

In genere vedrai le seguenti schede:

*   **Moduli**: Vai all'area [Moduli](../forms/index.md) per creare schemi di moduli, raccogliere dati e rivedere le risposte.
*   **Report**: Vai all'area [Report](../reports/index.md) per creare, visualizzare e gestire report basati sui dati raccolti.
*   **Metriche**: Vai all'area [Metriche](../metrics/index.md) per gestire dati di riferimento come progetti, posizioni e organizzazioni.
    !!! warning "Visibilità"
        La scheda Metriche è nascosta se il tuo account utente ha permessi di solo ospite.
*   **Utenti**: Vai all'area [Gestione utenti](../administration/users-list.md) per gestire account e gruppi utente.
    !!! tip "Accesso amministratore"
        La scheda Utenti è visibile solo agli utenti con privilegi di amministratore.

Per navigare, fai semplicemente clic sulla scheda dell'area a cui desideri accedere.

## Dashboard Report

In questo layout, la Dashboard è personalizzata per mostrare un singolo report che hai contrassegnato come preferito. Ciò ti consente di visualizzare le principali visualizzazioni dei dati immediatamente dopo l'accesso.

Se non hai ancora selezionato un report preferito, vedrai un messaggio di benvenuto che ti invita ad aggiungerne uno.

### Impostare un report preferito

1.  Vai all'area [Report](../reports/index.md).
2.  Apri il report che vuoi vedere nella tua Dashboard.
3.  Nell'elenco dei report o nella vista del report, trova e fai clic sull'azione **Aggiungi ai preferiti** (di solito rappresentata da un'icona a forma di cuore).
4.  Aggiorna o torna alla tua Dashboard. Il report selezionato verrà ora visualizzato.

### Modificare o rimuovere un preferito

Per cambiare il report preferito, aggiungi semplicemente un altro report ai preferiti. Il nuovo report sostituirà il vecchio nella tua Dashboard. Per svuotare la Dashboard, puoi rimuovere l'impostazione del report preferito dalla memoria locale del browser oppure contattare l'amministratore di sistema.
