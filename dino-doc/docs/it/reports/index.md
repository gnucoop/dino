# Report

L'area Report è il tuo punto di accesso a tutti gli schemi di report disponibili. Uno schema di report definisce la struttura e il contenuto di un report che può essere generato dai tuoi dati raccolti. Da qui puoi sfogliare gli schemi e accedere ai report già creati.

![Main view of the Reports page](../imgs/reports/index.png)

---

## Esplorare gli schemi di report

Quando apri la pagina Report, vedi un elenco di tutti gli schemi di report a cui hai il permesso di accedere. L'elenco è ordinato alfabeticamente per etichetta dello schema.

Per trovare uno schema specifico:

1. Usa la barra di ricerca nella parte superiore della pagina.
2. Digita qualsiasi parte del nome o dell'etichetta dello schema.
3. L'elenco si filtrerà in tempo reale per mostrare solo gli schemi corrispondenti.

Per visualizzare i report di uno schema specifico, fai clic sulla sua card nell'elenco.

!!! tip "Per iniziare"
    Se vedi il messaggio "Non ci sono report", significa che non sono ancora stati creati schemi di report o che non ti sono stati condivisi. Contatta il tuo amministratore Dino per iniziare.

---

## Creare un nuovo report

Puoi avviare il processo di generazione di un nuovo report direttamente dalla pagina principale Report.

1. Fai clic sul pulsante **+** (più) situato nell'angolo in basso a destra dello schermo.
2. Si aprirà un menu o una finestra di dialogo che ti permetterà di selezionare lo schema di report che desideri utilizzare.
3. Dopo aver selezionato uno schema, verrai indirizzato al modulo di creazione del report per scegliere le metriche, impostare un intervallo di date e generare il report.

!!! warning "Crediti richiesti"
    Alcuni schemi di report potrebbero richiedere crediti Dino-AI per essere generati. Se non hai abbastanza crediti, ti verrà chiesto di aggiungerne altri al tuo account prima di procedere.

Per passaggi dettagliati, consulta la guida su [Modifica report](edit-report.md).

---

## Cosa puoi fare

Dalla pagina principale Report, puoi navigare per eseguire queste azioni principali:

* **[Modifica report](edit-report.md)** — Genera un nuovo documento di report selezionando uno schema, scegliendo le metriche e impostando un intervallo di date.
* **[Modifica schema di report](edit-report-schema.md)** — Crea nuovi schemi di report o modifica quelli esistenti per definire quali dati appaiono nei report. Questa operazione richiede solitamente i permessi di amministratore.
