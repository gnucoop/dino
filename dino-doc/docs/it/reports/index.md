# Report

L'area Report è il tuo punto di accesso a tutti gli schemi di report disponibili. Uno schema di report definisce la struttura e il contenuto di un report che può essere generato dai tuoi dati raccolti. Da qui puoi esplorare gli schemi e accedere ai report già creati.

![Vista principale della pagina Report](../imgs/reports/index.png)

---

## Esplorare gli schemi di report

Quando apri la pagina Report, vedi un elenco di tutti gli schemi di report a cui hai accesso. L'elenco è ordinato alfabeticamente in base all'etichetta dello schema.

Per trovare uno schema specifico:

1. Usa la barra di ricerca nella parte superiore della pagina.
2. Digita una qualsiasi parte del nome o dell'etichetta dello schema.
3. L'elenco verrà filtrato in tempo reale per mostrare solo gli schemi corrispondenti.

Per visualizzare i report di uno schema specifico, fai clic sulla sua scheda nell'elenco.

!!! tip "Per iniziare"
    Se vedi il messaggio "Non ci sono report", significa che non è stato ancora creato o condiviso alcuno schema di report. Contatta l'amministratore di Dino per iniziare.

---

## Creare un nuovo report

Puoi avviare il processo di generazione di un nuovo report direttamente dalla pagina principale Report.

1. Fai clic sul pulsante **+** (più) situato nell'angolo inferiore destro dello schermo.
2. Si aprirà un menu o una finestra di dialogo che ti permetterà di selezionare lo schema di report da utilizzare.
3. Dopo aver selezionato uno schema, verrai portato al modulo di creazione del report per scegliere le metriche, impostare un intervallo di date e generare il report.

!!! warning "Crediti richiesti"
    Alcuni schemi di report potrebbero richiedere crediti Dino-AI per essere generati. Se non hai abbastanza crediti, ti verrà chiesto di aggiungerne altri al tuo account prima di procedere.

Per i passaggi dettagliati, consulta la guida su [Modifica report](edit-report.md).

---

## Cosa puoi fare

Dalla pagina principale Report puoi accedere alle seguenti azioni principali:

* **[Modifica report](edit-report.md)** — Genera un nuovo documento di report selezionando uno schema, scegliendo le metriche e impostando un intervallo di date.
* **[Modifica schema di report](edit-report-schema.md)** — Crea nuovi schemi di report o modifica quelli esistenti per definire quali dati compaiono nei report. Questa operazione richiede in genere i permessi di amministratore.
