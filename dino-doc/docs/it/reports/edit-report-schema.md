# Modifica dello schema di report

La pagina **Modifica dello schema di report** consente di creare un nuovo schema di report o modificarne uno esistente. Uno schema di report definisce la struttura, il layout e le origini dati per un report in Dino.

![Main view of the Edit Report Schema page](../imgs/reports/edit-report-schema.png)

In questa pagina puoi configurare il nome del report, la descrizione e i campi dati specifici che appariranno nel report a partire dagli invii dei moduli.

## Creazione di un nuovo schema di report

Per creare un nuovo schema di report:

1. Vai alla sezione **Report** nel menu principale.
2. Fai clic su **Crea schema di report**.
3. Si apre la pagina Modifica dello schema di report.
4. Inserisci un **Nome** descrittivo per il report.
5. (Facoltativo) Fornisci una **Descrizione** per spiegare lo scopo del report.
6. Configura i dati e il layout del report utilizzando le opzioni disponibili.
7. Fai clic su **Salva** per creare lo schema.

## Modifica di uno schema di report esistente

Per modificare uno schema di report già creato:

1. Vai alla sezione **Report**.
2. Trova nell'elenco lo schema di report che desideri modificare e fai clic su di esso.
3. Fai clic sul pulsante **Modifica** (spesso rappresentato da un'icona a forma di matita).
4. Si apre la pagina Modifica dello schema di report con la configurazione corrente caricata.
5. Apporta le modifiche desiderate al nome, alla descrizione o alla configurazione dei dati.
6. Fai clic su **Salva** per aggiornare lo schema.

!!! tip "Salvataggio del lavoro"
    Ricorda sempre di fare clic su **Salva** dopo aver apportato modifiche. Le modifiche non vengono applicate finché non salvi lo schema.

## Configurazione dei dati del report

Il cuore dello schema di report è la definizione di quali dati, provenienti dagli invii dei moduli, appariranno nel report. In genere puoi:

* **Seleziona origine dati:** scegli lo schema del modulo che contiene i dati su cui desideri creare il report.
* **Seleziona campi dati:** scegli campi specifici dagli schemi dei moduli collegati da includere come colonne nel report.
* **Imposta nomi visualizzati:** personalizza l'intestazione di colonna mostrata nel report per ciascun campo selezionato.
* **Definisci filtri:** imposta condizioni per includere solo specifici invii che soddisfano i tuoi criteri (ad esempio, invii compresi in un determinato intervallo di date).

!!! warning "Origine dati"
    Uno schema di report deve essere collegato ad almeno uno schema di modulo per avere dati da visualizzare. Assicurati che il modulo pertinente esista prima di creare il report.

## Passaggi successivi

Dopo aver salvato lo schema di report, puoi:

* Vai alla pagina [Report](index.md) per visualizzare ed eseguire il nuovo report.
* Torna a questa pagina per apportare ulteriori modifiche se necessario.
