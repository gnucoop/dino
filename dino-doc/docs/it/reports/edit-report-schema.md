# Modifica report schema

La pagina **Modifica report schema** ti permette di creare un nuovo report schema o di modificarne uno esistente. Un report schema definisce la struttura, il layout e le origini dati di un report in Dino.

![Vista principale della pagina Modifica report schema](../imgs/reports/edit-report-schema.png)

In questa pagina configuri il nome del report, la descrizione e i campi dati specifici che compariranno nel report a partire dai dati dei tuoi form.

## Creare un nuovo report schema

Per creare un nuovo report schema:

1. Vai alla sezione **Report** nel menu principale.
2. Fai clic su **Crea report schema**.
3. Vieni indirizzato alla pagina Modifica report schema.
4. Inserisci un **Nome** descrittivo per il tuo report.
5. (Facoltativo) Fornisci una **Descrizione** che spieghi lo scopo del report.
6. Importa un file XLSReport
7. Fai clic su **Salva** per creare lo schema.

## Modificare un report schema esistente

Per modificare un report schema che hai già creato:

1. Vai alla sezione **Report**.
2. Trova nell'elenco il report schema che vuoi modificare e fai clic su di esso.
3. Fai clic sul pulsante **Modifica** (spesso rappresentato da un'icona a forma di matita).
4. Vieni indirizzato alla pagina Modifica report schema con la configurazione attuale caricata.
5. Apporta le modifiche desiderate al nome, alla descrizione o alla configurazione dei dati.
6. Fai clic su **Salva** per aggiornare lo schema.

!!! tip "Salvare il proprio lavoro"
    Ricorda sempre di fare clic su **Salva** dopo aver apportato modifiche. Le modifiche non vengono applicate finché non salvi lo schema.

## Configurare i dati del report

Il cuore del report schema è definire quali dati dei tuoi form compariranno nel report. In genere puoi:

* **Selezionare l'origine dati:** Scegli il form schema che contiene i dati su cui vuoi creare il report.
* **Selezionare i campi dati:** Scegli campi specifici dai form schema collegati da includere come colonne nel report.
* **Impostare i nomi visualizzati:** Personalizza l'intestazione di colonna mostrata nel report per ogni campo selezionato.
* **Definire i filtri:** Imposta condizioni per includere solo i dati specifici che soddisfano i tuoi criteri (ad esempio, i dati relativi a un determinato intervallo di date).

!!! warning "Origine dati"
    Un report schema deve essere collegato ad almeno un form schema per avere dati da mostrare. Assicurati che il form interessato esista prima di creare il report.

## Passaggi successivi

Dopo aver salvato il report schema, puoi:

* Andare alla pagina [Report](index.md) per visualizzare ed eseguire il tuo nuovo report.
* Tornare a questa pagina per apportare ulteriori modifiche se necessario.
