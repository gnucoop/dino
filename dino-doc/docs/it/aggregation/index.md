# Aggregazione

La pagina Aggregazione offre una vista unificata di tutte le sottomissioni dei moduli della tua organizzazione. Invece di visualizzare le sottomissioni per un singolo schema di modulo alla volta, puoi vedere le voci di più schemi insieme in un unico elenco filtrabile.

![Vista principale della pagina Aggregazione](../imgs/aggregation/index.png)

## Sfogliare l'elenco

L'elenco mostra tutte le sottomissioni che hai il permesso di visualizzare. Ogni riga rappresenta una singola sottomissione. Le seguenti colonne sono visualizzate per impostazione predefinita:

*   **Schema del modulo**: Il nome dello schema di modulo a cui appartiene questa sottomissione.
*   **Stato**: Lo stato corrente del flusso di lavoro della sottomissione.
*   Potrebbero apparire anche colonne aggiuntive per metriche come **Progetto**, **Sede** o **Organizzazione**, a seconda della configurazione del tuo sistema.

Puoi cliccare su qualsiasi riga per selezionarla o espanderla per vedere maggiori dettagli.

## Filtrare l'elenco

Una barra di filtro si trova sopra l'elenco. Usala per restringere le sottomissioni mostrate. Puoi filtrare per:

*   Progetto
*   Sede
*   Area
*   Caso
*   Codice caso
*   Organizzazione
*   Stato del modulo
*   Utente

!!! tip "Suggerimenti per il filtraggio"
    La barra di filtro dell'Aggregazione è progettata per un filtraggio rapido tra più schemi. Per funzionalità avanzate come preset di filtro salvati o esportazione dati, vai all'[elenco delle sottomissioni per uno schema di modulo specifico](../forms/index.md).

## Azioni sulle righe

Quando passi il mouse su una riga, appare un insieme di icone di azione a destra. Le azioni disponibili per una specifica sottomissione dipendono dai tuoi permessi per il suo schema di modulo.

*   **Visualizza**: Apre la sottomissione in una vista di sola lettura.
*   **Modifica**: Apre la sottomissione per la modifica.
*   **Stampa**: Genera e apre una versione PDF della sottomissione. Ti verrà chiesto di confermare prima della creazione del PDF.
*   **Elimina**: Elimina permanentemente la sottomissione. Ti verrà chiesto di confermare questa azione.

## Creare una nuova sottomissione

Puoi avviare una nuova sottomissione direttamente dalla pagina Aggregazione.

1.  Clicca sul pulsante **+** (Aggiungi) nell'angolo in basso a destra dello schermo.
2.  Si apre una finestra di dialogo che mostra un elenco degli schemi di modulo per cui hai il permesso di creare sottomissioni.
3.  Seleziona lo schema di modulo desiderato dall'elenco.
4.  Clicca su **Crea modulo**. Verrai portato al modulo per iniziare a compilarlo.
