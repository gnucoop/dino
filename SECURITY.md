# Security Policy

## Supported Versions

We currently support the latest version of the project with security updates.

| Version | Supported          |
| ------- | ------------------ |
| current | :white_check_mark: |
| < current| :x:                |

## Reporting a Vulnerability

**Please do not open public GitHub issues for security vulnerabilities.**

If you discover a security vulnerability within this project, please report it privately using GitHub's **Private Vulnerability Reporting** feature. 

To do this:
1. Go to the main page of this repository.
2. Click on the **Security** tab.
3. Click on **Advisories** on the left sidebar, then click **Report a vulnerability**.

Alternatively, you can contact the maintainers directly via email at: **dev@gnucoop.com**

We take security seriously and will review your report as soon as possible.
