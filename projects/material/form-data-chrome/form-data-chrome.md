The `@dino/material/form-data-chrome` module provides the `dino-form-data-chrome` component: the redesigned navigation/action chrome that wraps an Ajf `<ajf-form>` renderer. It replaces the Ajf built-in toolbars with a section select + searchable picker overlay, a repeating-record pager, a "more below" scroll hint, prev/next section FABs and save actions, driving the form entirely through the `AjfFormRenderer` public API.
